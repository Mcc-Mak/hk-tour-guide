### 導賞路線建議

本導賞路線共設七個站點，建議總時長約45至60分鐘，可根據實際情況調整停留時間：

1. **第一站：紅磡灣填海歷史——從海床到商業區**（約8分鐘）
   - 面向維多利亞港方向，觀察地面與海平面的關係，了解填海工程對紅磡灣海岸線的影響。

2. **第二站：雙塔低層設計——打破「愈高愈好」的思維**（約7分鐘）
   - 退後數步，將東座與西座一併觀察，留意高度比例及兩座大樓之間的空間關係。

3. **第三站：玻璃幕牆與遮陽百葉——功能與美學的結合**（約8分鐘）
   - 行近大樓外牆，觀察玻璃幕牆系統及水平向遮陽百葉的細節，留意光影變化。

4. **第四站：維港海景——甲級商廈的無形資產**（約6分鐘）
   - 轉身面向維多利亞港，感受海景視野，留意東座與西座的朝向與海景關係。

5. **第五站：從土地招標到落成——One Harbour Gate 的誕生**（約8分鐘）
   - 面向大樓入口，觀察建築規模與完成度，了解項目由土地取得至全面竣工的歷程。

6. **第六站：甲級寫字樓規格——入面有甚麼特別？**（約7分鐘）
   - 留意大堂入口設計、大堂樓底高度及電梯大堂配置，認識甲級寫字樓的規格標準。

7. **第七站：紅磡灣的蛻變——從工業區到新商業區**（約6分鐘）
   - 環顧四周，觀察紅磡灣一帶的建築類型（商廈、酒店、住宅、海濱長廊等），理解地區轉型脈絡。

> **互動建議**：每個站點均設有「現場觀察重點」，導賞員應引導參加者親自觀察同感受，而非單向講解。

## 二、歷史脈絡與建築特色

### 建築風格與特色

One Harbour Gate 採用**現代商業建築風格**，其主要建築特色包括：

- **雙塔低層設計**：有別於香港常見的超高層商廈（如國際金融中心 IFC、環球貿易廣場 ICC），One Harbour Gate 以兩座約15層的低層辦公大樓組成，營造更親切的建築尺度。此設計選擇回應了紅磡灣海濱的城市規劃高度限制，同時與周邊酒店及住宅建築形成協調的海濱建築群。
- **玻璃幕牆立面**：外牆採用現代化玻璃幕牆系統，配合水平向遮陽百葉（horizontal louvres），兼具美觀與節能功能。玻璃幕牆最大化自然採光並提供無遮擋的維港海景，遮陽百葉則遮擋高角度直射陽光，同時容許低角度光線進入，兼顧遮陽與採光需求。
- **海濱景觀優勢**：坐落於紅磡灣海濱，面向維多利亞港，東座及西座均可享有開揚海景。海濱位置為甲級寫字樓的重要商業價值因素，直接影響企業形象與員工工作環境質素。
- **甲級辦公規格**：樓底高度、空調系統、電梯配置及樓面負載均達甲級寫字樓標準，面向金融、專業服務及跨國企業租戶。空調系統可24小時運作，滿足跨國企業不同時區的工作需要。
- **可持續建築元素**：符合現代綠色建築標準，可能具備 BEAM Plus 或同類綠色建築認證（需進一步查核，目前標記為 CL 1 未經證實）。

### 歷史事件與背景

#### 地區填海與土地規劃期

- 1970s–1990s：紅磡灣一帶經歷大規模填海工程，將原有海岸線大幅向外推移，為後續商業、住宅及社區設施發展提供土地資源。One Harbour Gate 所處地段即為紅磡灣填海區的一部分。
- 2000s：紅磡灣填海區逐步納入九龍南部的城市發展規劃框架，城市規劃委員會就該區的土地用途進行分區計劃大綱圖（OZP）修訂，確立商業及住宅發展方向。

#### 土地批租與項目規劃期

- 約2010–2011年：會德豐地產有限公司透過政府土地招標程序取得紅磡灣商業用地發展權。該地段屬政府勾地表內的商業用地，以招標方式批出。
- 約2012–2013年：項目進入詳細規劃及建築設計階段，發展商向城市規劃委員會提交規劃申請，並向屋宇署提交建築圖則審批。方案確立為雙塔甲級商業辦公大樓設計。

#### 建設期

- 約2013–2014年：One Harbour Gate 項目正式動工興建，地基及主體結構工程陸續展開。項目分為東座（East Tower）及西座（West Tower）兩座辦公大樓。填海土地的地質條件較為複雜，地基工程為關鍵環節。
- 約2015年：建築結構逐步封頂，幕牆安裝及內部機電工程進入關鍵階段。
- 約2016年：西座（West Tower）率先落成，取得屋宇署發出的佔用許可證（入伙紙），正式具備使用條件。
- 約2017年：東座（East Tower）落成並取得佔用許可證，整個 One Harbour Gate 項目全面竣工。

#### 營運與租務期

- 2017年起：One Harbour Gate 正式投入營運，陸續有企業租戶進駐。主要租戶涵蓋金融服務、專業顧問、科技及跨國企業等行業。
- 2018–2020年：大廈租務逐步穩定，成為紅磡灣海濱商業區的標誌性甲級辦公大樓之一。與同區的 Kerry Hotel、海韻軒等發展項目共同構成紅磡灣新商業及酒店區。
- 2020年至今：受新冠疫情及香港經濟環境變化影響，甲級寫字樓租務市場面臨挑戰，One Harbour Gate 亦受整體市場趨勢影響，但憑藉海濱位置及甲級規格維持一定競爭力。

#### 建築導賞與公眾關注期

- 近年：One Harbour Gate 作為紅磡灣海濱的現代商業建築代表，被納入「香港樓宇導賞團」類別，供公眾及建築愛好者了解香港現代商業建築設計及紅磡灣地區發展歷程。

各位朋友，歡迎參加今日嘅香港樓宇導賞團。我係今日嘅導賞員，好高興可以同大家一齊探索紅磡灣海濱嘅現代商業建築——One Harbour Gate。

我哋而家企喺紅鸞道呢度，望向前面呢兩座玻璃幕牆大樓，就係今日導賞嘅主角。大家不妨先停低腳步，抬頭望一望——你哋覺得呢兩座大廈，同香港其他商業大廈有咩分別呢？

冇錯，最明顯嘅分別就係——佢哋唔算好高。喺香港呢個充滿摩天大廈嘅城市，我哋習慣咗見到中環嘅IFC、西九龍嘅ICC，動輒六七十層甚至更高。但係 One Harbour Gate 兩座大樓每座大約只有15層左右，呢個「低層雙塔」嘅設計，正正係佢最特別嘅地方。呢個設計選擇背後，其實反映咗發展商對紅磡灣海濱環境嘅一種回應——我哋等陣會詳細講到。

### 各站點

### 第一站：紅磡灣填海歷史——從海床到商業區

#### 現場觀察重點

> 請大家面向維多利亞港方向，留意我哋腳下嘅地面同海平面嘅關係。

#### 歷史故事

要講 One Harbour Gate 嘅故事，我哋首先要由「土地」講起。

大家而家企嘅位置，其實喺幾十年前——係海底。

紅磡灣一帶由1970年代至1990年代，經歷咗大規模嘅填海工程。呢啲填海工程將原本嘅海岸線大幅向外推移，為九龍南部分區提供咗大量土地資源。如果你哋有機會翻查規劃署歷年嘅規劃圖則，就可以清楚見到紅磡灣嘅海岸線點樣一步一步向外擴展。

填海得返嚟嘅土地，最初主要用作工業同社區設施。但係去到2000年代，城市規劃委員會開始將紅磡灣填海區納入更全面嘅城市發展規劃框架，透過修訂分區計劃大綱圖——即係城規會嘅 OZP——確立咗呢一區嘅商業同住宅發展方向。

所以，One Harbour Gate 所處嘅地段，本身就係香港城市規劃同土地發展嘅產物。由海底變成土地，再由工業預留地變成甲級商業用地——呢個轉變過程，用咗幾十年時間。

### 第二站：雙塔低層設計——打破「愈高愈好」的思維

#### 現場觀察重點

> 請大家退後幾步，盡量將東座同西座兩座大樓一齊收入眼簾。留意佢哋嘅高度比例同埋兩座大樓之間嘅空間關係。

#### 歷史故事

好，我哋而家認真睇下呢兩座大樓嘅建築設計。

One Harbour Gate 由會德豐地產有限公司發展，分為東座同西座——東座門牌係紅鸞道18號，西座係紅鸞道20號。兩座大樓各約15層，採用現代商業建築風格設計。

大家可能會問：點解喺香港呢個地價咁高嘅地方，發展商唔起高啲呢？畢竟起得愈高，可租用面積就愈多，回報就愈高。

呢個問題好值得思考。其實，紅磡灣海濱嘅城市規劃對建築高度有一定限制，呢個同機場航道、海濱景觀保護同埋分區規劃有關。但同時，低層設計亦帶嚟一個好處——就係營造出一個更親切嘅建築尺度。

大家試下對比一下：你企喺IFC下面，抬頭望上去，係一種被巨大建築壓迫嘅感覺；但係企喺 One Harbour Gate 前面，15層嘅高度其實同周邊嘅酒店同住宅建築比較協調，形成一個更舒適嘅海濱建築群。

呢種「低層雙塔」嘅設計，喺香港嘅甲級商廈中其實唔常見。佢選擇咗一種「橫向發展」而非「豎向發展」嘅策略，用兩座大樓嘅總面積去彌補單座高度嘅不足。

### 第三站：玻璃幕牆與遮陽百葉——功能與美學的結合

#### 現場觀察重點

> 請大家行近少少，留意大樓外牆嘅玻璃幕牆同埋上面嘅水平向遮陽百葉。如果陽光啱啱照射到外牆，可以觀察光影嘅變化。

#### 歷史故事

我哋而家行近少少，睇下大樓嘅外牆細節。

One Harbour Gate 嘅立面採用現代化玻璃幕牆系統，配合水平向遮陽百葉。呢兩個元素唔單止係美觀考慮，仲有好強嘅功能性。

玻璃幕牆係現代商業建築嘅標誌性元素，佢可以最大化自然採光，令辦公室內部更加明亮，同時亦都提供咗無遮擋嘅維港海景——呢個對甲級寫字樓嘅租戶嚟講係好重要嘅賣點。

但係玻璃幕牆有一個天生嘅問題：就係太陽輻射熱。香港夏天咁熱，如果全玻璃幕牆冇遮擋，冷氣負荷會好驚人。所以大家留意到，幕牆外面加裝咗水平向嘅遮陽百葉。呢啲百葉可以遮擋高角度嘅直射陽光，同時又容許低角度嘅光線進入，兼顧咗遮陽同採光嘅需要。

呢種設計反映咗現代商業建築對節能同環保嘅關注。香港嘅商業建築係主要嘅能源消耗者，點樣喺設計階段就引入被動式節能策略，係近年建築設計嘅重要課題。

順帶一提，現代香港商業建築通常會追求綠色建築認證，例如香港綠色建築議會嘅 BEAM Plus 認證。不過，One Harbour Gate 係咪確實取得咗呢個認證，就需要進一步向相關機構查證喇。

### 第四站：維港海景——甲級商廈的無形資產

#### 現場觀察重點

> 請大家轉身面向維多利亞港，感受一下由大樓位置望出去嘅海景視野。留意東座同西座嘅朝向同海景關係。

#### 歷史故事

大家而家轉身望向海嗰邊。

One Harbour Gate 坐落於紅磡灣海濱，面向維多利亞港。東座同西座嘅設計令到兩座大樓都可以享有開揚嘅海景。

喺香港嘅商業地產市場，「海景」係一個好重要嘅價值因素。對於跨國企業、金融服務公司、專業顧問行呢類甲級寫字樓嘅目標租戶嚟講，辦公室嘅景觀直接影響到企業形象同員工嘅工作環境質素。

維多利亞港嘅海景，可以話係香港商業地產嘅「無形資產」。同一面積嘅寫字樓，有海景同冇海景嘅租金可以差好遠。所以，One Harbour Gate 嘅海濱位置，係佢喺甲級寫字樓市場競爭嘅一大優勢。

大家亦可以留意一下周邊嘅發展。同區有嘉里酒店、海韻軒等項目，共同構成咗紅磡灣新嘅商業及酒店區。呢個區域嘅發展，反映咗九龍南部分區規劃嘅策略——將海濱用地優先用於商業、酒店同休閒用途，令海濱更加有活力。

### 第五站：從土地招標到落成——One Harbour Gate 的誕生

#### 現場觀察重點

> 請大家面向大樓入口，留意建築嘅規模同完成度。想像一下呢棟大樓由空地到落成嘅過程。

#### 歷史故事

好，我哋而家講下 One Harbour Gate 點樣由無到有。

大約喺2010至2011年期間，會德豐地產透過政府嘅土地招標程序，取得咗紅磡灣呢幅商業用地嘅發展權。呢幅地屬於政府勾地表內嘅商業用地，以招標方式批出。所謂「勾地表」制度，係香港政府以前用嚟管理土地供應嘅機制——發展商可以申請將勾地表內嘅土地推出市場拍賣或招標。

取得土地之後，大約2012至2013年，項目進入詳細規劃同建築設計階段。發展商要向城市規劃委員會提交規劃申請，同時向屋宇署提交建築圖則審批。呢個過程確立咗雙塔甲級商業辦公大樓嘅設計方案。

大約2013至2014年，項目正式動工興建。地基同主體結構工程陸續展開。大家要知道，喺紅磡灣呢個填海區起樓，地基工程係好關鍵嘅——填海土地嘅地質條件比較複雜，需要打樁打到好深先可以確保建築物嘅穩固。

大約2016年，西座率先落成，取得屋宇署發出嘅佔用許可證——即係我哋俗稱嘅「入伙紙」。到2017年，東座亦都落成並取得入伙紙，整個 One Harbour Gate 項目全面竣工。

不過我要補充一句，呢啲日期有部分係根據公開資料同市場慣例推算嘅約略年份。如果大家想知最確實嘅完工日期，就需要去屋宇署查閱佔用許可證嘅簽發紀錄喇。

### 第六站：甲級寫字樓規格——入面有甚麼特別？

#### 現場觀察重點

> 如果可以嘅話，請大家留意大堂入口嘅設計、大堂樓底高度同埋電梯大堂嘅配置。

#### 歷史故事

One Harbour Gate 達到甲級寫字樓嘅規格，呢個意味住乜嘢呢？

喺香港，寫字樓分為甲、乙、丙三個等級。甲級寫字樓喺樓底高度、空調系統、電梯配置、樓面負載等各方面都要達到一定標準。例如，樓底要有足夠高度去容納現代化嘅天花系統同地板下嘅佈線空間；空調系統要能夠24小時運作，滿足跨國企業唔同時區嘅工作需要；電梯要夠多夠快，減少上下班高峰期嘅等候時間。

One Harbour Gate 嘅目標租戶主要係金融服務、專業顧問、科技同跨國企業。呢類企業對辦公環境嘅要求好高，唔單止要功能完善，仲要能夠反映企業形象。

由2017年正式投入營運以嚟，One Harbour Gate 陸續有企業租戶進駐。到2018至2020年期間，大廈嘅租務逐步穩定，成為紅磡灣海濱商業區嘅標誌性甲級辦公大樓之一。

不過，由2020年開始，受新冠疫情同香港經濟環境變化影響，甲級寫字樓租務市場面臨挑戰。One Harbour Gate 亦都受到整體市場趨勢嘅影響。但係憑住海濱位置同甲級規格，佢維持住一定嘅競爭力。

### 第七站：紅磡灣的蛻變——從工業區到新商業區

#### 現場觀察重點

> 請大家環顧四周，留意紅磡灣一帶嘅建築類型——商廈、酒店、住宅、海濱長廊等。

#### 歷史故事

最後，我哋將 One Harbour Gate 放返喺紅磡灣地區發展嘅脈絡入面去理解。

紅磡呢個地方，以前係香港重要嘅工業區同船塢所在地。黃埔船塢就喺附近，係香港歷史上最重要嘅造船設施之一。隨住香港經濟轉型，工業同造船業逐漸式微，紅磡灣一帶嘅土地用途亦都跟住轉變。

填海工程創造咗新嘅土地，城市規劃重新定義咗呢一區嘅功能。去到2010年代，紅磡灣已經發展成一個集商業、酒店、住宅同海濱休閒於一身嘅綜合區域。

One Harbour Gate 嘅出現，正正係呢個轉型過程嘅一部分。佢代表咗紅磡灣從工業及船塢用地，轉型為新興商業及酒店區嘅城市發展脈絡。同時，佢亦都展示咗現代香港商業建築喺設計、功能同可持續性方面嘅最新趨勢。

### 結語

各位朋友，今日我哋透過 One Harbour Gate 呢座建築，認識咗紅磡灣由海底變成土地、由工業區變成商業區嘅發展歷程。我哋亦都了解到現代甲級商廈喺建築設計上嘅各種考量——由雙塔低層嘅尺度選擇，到玻璃幕牆配遮陽百葉嘅節能策略，到海濱位置嘅商業價值。

One Harbour Gate 雖然唔係古蹟，但佢記錄咗香港城市發展嘅一個階段——一個由追求高度轉向追求質量、由忽視環境轉向關注可持續性嘅階段。每一座建築都係佢所處時代嘅縮影，而 One Harbour Gate 就係2010年代香港商業建築嘅一個縮影。

多謝大家今日嘅參與，希望呢次導賞可以令大家對香港嘅現代商業建築同城市發展有更深嘅認識。如果有任何問題，歡迎而家提出，我哋一齊討論。

> 2. **檔案查閱途徑**：上述政府部門的檔案系統大多提供線上查詢功能，但部分詳細紀錄（如完整建築圖則、地契全文）可能需要親身前往相關部門辦事處查閱或申請副本。
> 3. **日期準確性**：本手冊中部分日期為根據公開資料及市場慣例推算的約略年份。確實的動工日期、完工日期及入伙紙簽發日期應以屋宇署的官方紀錄為準。
> 4. **後續研究建議**：
>    - 向屋宇署申請查閱 One Harbour Gate 的建築圖則及佔用許可證紀錄，以確認確實完工日期及建築規格。
