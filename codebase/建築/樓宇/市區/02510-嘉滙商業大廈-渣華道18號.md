## 二、歷史脈絡與建築特色

### 建築風格與特色

嘉滙商業大廈屬於1970至1980年代香港典型的商業大廈建築風格，具以下特徵：

1. **實用主義設計**：建築以功能性為主導，外觀簡潔，缺乏裝飾性元素，反映當時追求經濟效益的建築取向。
2. **鋼筋混凝土結構**：採用當時普遍的鋼筋混凝土框架結構，提供標準化的樓層平面。
3. **玻璃幕牆與窗戶設計**：外牆結合玻璃窗戶與混凝土牆面，屬該時期商業大廈的常見處理手法。
4. **分層出租設計**：樓層平面設計便於分層分單位出租，適合中小型企業使用。

### 歷史事件與背景

#### 戰後北角發展期

- 1950年代：渣華道一帶在戰後逐漸發展成北角的主要商業街道之一。渣華道英文名稱為 Java Road，以印尼爪哇島命名，源於早期該處海旁有荷蘭輪船公司（如爪哇中國日本線，Java-China-Japan Line）的碼頭及倉庫，連接英皇道與東區走廊，是北角區的交通要道。
- 1960年代：北角區在戰後工業化浪潮中迅速發展，渣華道沿線陸續興建多層商業及工業大廈，以應付日益增長的工商業需求。

#### 城市現代化與商廈興建

- 1970年代：隨著香港經濟起飛，北角渣華道一帶的舊式建築逐步被現代化商業大廈取代。嘉滙商業大廈在此背景下興建，屬於該時期典型的分層商業大廈發展項目。
- 1970年代後期至1980年代初：嘉滙商業大廈落成入伙，為一座多層商業大廈，提供分層辦公室單位，主要服務中小型企業。建築設計屬實用主義風格，外牆以混凝土及玻璃幕牆為主要物料，反映當時香港商業建築的典型特徵。

#### 經濟轉型與社區變遷

- 1990年代：隨著香港製造業北移，北角一帶的工業及商業大廈用途逐漸轉型，部分單位改作服務行業及專業辦公室用途。嘉滙商業大廈亦跟隨此趨勢，租戶結構趨向多元化。
- 2000年代至今：北角渣華道一帶持續城市更新，嘉滙商業大廈作為區內其中一座商業大廈，持續為中小型企業提供辦公空間。大廈鄰近港鐵北角站，交通便利，維持一定的商業價值。

## 五、導賞員現場講稿

### 開場白

各位團友，大家好！歡迎參加今日的北角歷史建築導賞團。我哋現在身處的位置，是北角渣華道。請大家將目光投向我面前的這座大廈——「嘉滙商業大廈」。

可能好多團友會問：「呢座大廈睇落冇咩特別，點解會帶我哋嚟呢度睇？」其實，要了解香港戰後的城市發展同經濟起飛，我哋唔一定要睇唐樓或者古老廟宇。呢一座建於上世紀七、八十年代嘅商業大廈，正正係北角由戰後工業區，轉型為現代化商業社區嘅最佳見證。今日，我就帶大家由呢度出發，解讀北角嘅時代變遷。

### 各站點

### 渣華道的名字之謎

#### 現場觀察重點

- 引導團友留意渣華道街道牌上的英文名稱 "Java Road"。
- 指向遠處海旁方向，說明早期北角海岸線與碼頭位置。
- 提示團友思考街名與國際航運的關係。

#### 歷史故事

喺我哋欣賞座大廈之前，我想同大家講吓我哋企緊嘅呢條馬路——「渣華道」。大家知唔知「渣華」呢個名係點嚟嘅呢？

可能有朋友會估，係咪同某位英國海軍軍官有關？其實唔係㗎！渣華道嘅英文名係 "Java Road"，即係印尼「爪哇島」嘅意思。點解北角會同印尼扯上關係？

原來喺早期，北角呢一帶嘅海旁，係有荷蘭輪船公司（例如爪哇中國日本線，Java-China-Japan Line）嘅碼頭同倉庫。因為咁，呢條路就被命名為 Java Road，中文就音譯做「渣華道」。所以，呢個街名本身就記錄咗香港早期作為國際航運樞紐嘅歷史。由1950年代開始，渣華道就逐漸發展成為北角嘅主要商業街道，連接住英皇道同東區走廊，係區內嘅交通大動脈。

### 實用主義的建築美學

#### 現場觀察重點

- 引導團友抬頭仰望大廈外牆，觀察窗戶排列與物料搭配。
- 指出混凝土牆面與玻璃窗戶的比例分佈。
- 提示團友比較此大廈與中環摩天大廈在裝飾元素上的差異。

#### 歷史故事

好，而家我哋將視線拉返落嚟，認真睇吓面前嘅嘉滙商業大廈。

呢座大廈大約係喺1970年代後期至1980年代初落成嘅。大家不妨抬頭望吓佢嘅外觀，你會發現佢嘅設計非常「簡約」，甚至可以話係「冇花臣」。呢種風格，喺建築學上叫做「實用主義」。

大家留意吓佢嘅外牆，主要係用混凝土加上玻璃幕牆同玻璃窗戶組合而成。呢種設計喺當年嘅香港非常流行。點解會咁？因為1970年代香港經濟起飛，對辦公空間需求極大，發展商起樓講求經濟效益同效率。建築師就採用咗鋼筋混凝土框架結構，提供標準化嘅樓層平面，外觀唔會加太多裝飾，將資源集中喺提供實用嘅辦公面積。

大家可以見到，大廈係設計成分層出租嘅模式，入面有好多細小嘅辦公室單位。呢種設計，正正係為咗迎合當時如雨後春筍般湧現嘅中小型企業。呢座大廈，就好似一個容器，盛載住無數香港人創業打拼嘅故事。

### 見證經濟轉型的活化石

#### 現場觀察重點

- 指向大廈入口或大堂，暗示內裡的租戶結構變化。
- 引導團友留意大廈周邊其他商廈的用途轉變跡象。
- 提示團友觀察大廈鄰近港鐵北角站的地理優勢。

#### 歷史故事

建築物嘅生命力，在於佢點樣隨住時代轉變而改變用途。嘉滙商業大廈唔單止見證咗70年代嘅經濟起飛，亦都經歷咗香港經濟結構嘅重大轉型。

喺1960到70年代，北角區係一個工業化嘅重鎮，渣華道沿線有好多工廠同商業大廈。但去到1990年代，隨住香港製造業大規模北移到內地，北角嘅工廈同商廈用途就面臨轉型。

嘉滙商業大廈都唔例外。以前入面可能好多係貿易公司、採購辦公室，甚至同工業生產相關嘅寫字樓；但到咗90年代之後，租戶結構開始多元化，慢慢轉型做服務行業、專業辦公室，例如會計師樓、律師行、醫務所等等。直到而家，北角渣華道一帶持續進行城市更新，呢座大廈依然企喺度，繼續為中小企提供緊辦公空間。加上佢鄰近港鐵北角站，交通極之方便，依然維持住好高嘅商業價值。

### 結語

各位團友，今日我哋企喺嘉滙商業大廈面前，可能你會覺得佢比唔上中環嗰啲玻璃幕牆摩天大廈咁宏偉。但係，當我哋了解咗佢背後嘅故事——由渣華道嘅航運歷史，到70年代實用主義嘅建築風格，再到90年代嘅經濟轉型——你就會發現，呢座大廈其實係一本立體嘅歷史書。

佢冇華麗嘅外衣，但佢用最務實嘅姿態，陪伴住北角區走過幾十年嘅變遷，記錄咗香港中小企拼搏嘅精神。呢個就係我哋今日導賞嘅意義：喺平凡嘅街道同建築中，讀出不平凡嘅香港故事。

好啦，我哋喺度大約停留多五分鐘俾大家影相，之後我哋就會行去下一個景點，繼續探索北角嘅社區變遷。多謝大家！

9. [`CL 3：北角街坊會`](https://www.northpoint.org.hk/) — 北角街坊福利會，保存北角區社區發展的歷史資料，可作為民間記錄的補充參考。
