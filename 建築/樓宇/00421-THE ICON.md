## 二、歷史脈絡與建築特色

### 建築風格與特色

THE ICON 屬於**現代主義商業建築**風格，具備以下特徵：

- **玻璃幕牆外立面**：採用現代化玻璃幕牆設計，與傳統工業大廈的混凝土外牆形成鮮明對比，象徵觀塘由工業區向商業區的轉型。玻璃幕牆反射周邊環境，包括舊式建築與新建商廈，隱喻新舊交替的城市景觀。
- **功能性空間規劃**：大廈以寫字樓為主要用途，地面及低層設零售空間，符合現代商業大廈的混合用途模式。此設計與傳統工廠大廈地面層用作上落貨區的功能形成顯著差異。
- **現代化設施**：配備高速升降機、中央空調系統及現代化物業管理設施，迎合商業租戶需求。大廈入口採商業化門廊與大堂設計，呈現專業開放的商業形象。
- **建築語彙的轉型隱喻**：由混凝土外牆到玻璃幕牆的轉變，不僅是建材的更替，更象徵觀塘由「生產製造」走向「商業服務」的根本性城市功能轉型。

### 歷史事件與背景

#### 觀塘工業區時期

- 1950年代：香港政府將觀塘劃為首個新市鎮及工業區，觀塘道一帶開始大規模填海及工業發展，成為九龍東主要工業走廊。
- 1960-1970年代：觀塘道沿線興建大量工廠大廈，成為香港製造業重鎮，紡織、塑膠、電子等工業蓬勃發展。
- 1980年代：觀塘工業區達至鼎盛，區內工廠大廈林立，就業人口密集。

#### 工業轉型與重建期

- 1990年代：隨著香港製造業北移，觀塘工業區逐漸式微，大量工廠大廈空置或低效使用。
- 2001年：政府推出「工業用地改作商業用途」政策，容許觀塘等舊工業區的工業大廈重建或改裝為商業用途，為觀塘道一帶的重建奠定政策基礎。

#### 觀塘商業化與 THE ICON 建設期

- 2000年代中後期：恆基兆業地產有限公司收購觀塘道320-322號原工業大廈地段，計劃重建為現代化商業大廈。
- 約2010-2012年：THE ICON 動工興建，為觀塘道沿線工業轉商業的重建項目之一，反映九龍東轉型為商業核心區（CBD2）的城市發展策略。
- 約2013-2014年：THE ICON 落成入伙，提供現代化寫字樓空間，配合政府「起動九龍東」計劃，推動觀塘由傳統工業區轉型為商業樞紐。

#### 九龍東 CBD2 發展期

- 2012年：政府正式啟動「起動九龍東」計劃，將觀塘、九龍灣及啟德發展區定位為香港第二個商業核心區（CBD2），THE ICON 作為觀塘道沿線新建商業大廈，受惠於此政策。
- 2010年代後期至今：觀塘道一帶持續有新商業項目落成，THE ICON 與周邊重建項目共同塑造觀塘新商業面貌。

### 第二站：觀塘工業區的黃金歲月

好，等我哋行前少少，我同大家講下觀塘工業區嘅故事。

1950年代，香港政府做咗一個好重要嘅決定：將觀塘劃為香港首個新市鎮同埋工業區。當時政府喺觀塘道一帶進行大規模填海，開闢土地興建工廠大廈。你哋而家企嘅呢段觀塘道，當年就係九龍東最主要嘅工業走廊。

去到1960至70年代，觀塘工業區進入咗黃金時期。紡織、塑膠、電子、鐘錶……各種製造業喺度蓬勃發展。當時嘅觀塘道，朝早六七點就開始熱鬧，工廠妹成群結隊返工，巴士、小巴塞滿條路，貨車喺工廠門口排住隊等上落貨。根據統計，觀塘工業區全盛時期僱用咗數以萬計嘅工人，係香港製造業嘅重鎮。

到咗1980年代，觀塘工業區達到鼎盛，區內工廠大廈林立，就業人口密集。嗰陣時，如果你話你喺觀塘返工，人人都知你係工廠人。

但係，繁華背後，轉變已經悄悄醞釀。

#### 現場觀察重點

- 觀察觀塘道的道路寬度與走向，想像當年工廠貨車密集行駛的情景
- 留意道旁仍保留的舊式工業大廈，觀察其建築特徵（混凝土外牆、小窗戶、貨物升降機入口）
- 注意街道名稱或周邊建築物名稱中可能保留的工業歷史痕跡

#### 歷史故事

1950年代，香港政府將觀塘劃為首個新市鎮及工業區，觀塘道一帶開始大規模填海及工業發展，成為九龍東主要工業走廊。1960至1970年代，觀塘道沿線興建大量工廠大廈，紡織、塑膠、電子等工業蓬勃發展，成為香港製造業重鎮。1980年代，觀塘工業區達至鼎盛，區內工廠大廈林立，就業人口密集。呢段黃金歲月，唔單止係觀塘嘅驕傲，更加係香港經濟起飛嘅重要基石。當年無數工廠工人嘅汗水同努力，就係今日觀塘轉型嘅歷史底蘊。

---

### 第三站：工業北移與空置的工廈

各位團友，我哋而家轉個身，望一望觀塘道兩旁。你哋會發現一個有趣嘅現象：有啲大廈好新好靚，有啲就明顯殘舊，甚至有啲地下舖頭仲保留住工廠時代嘅痕跡。

呢個現象背後，反映咗1990年代一個好重要嘅歷史轉折。

1990年代開始，隨住中國大陸改革開放，香港製造業大規模北移。工廠老闆發現，將生產線搬去深圳、東莞，成本平一大截。於是，一間接一間嘅工廠關門、搬遷，觀塘工業區開始出現大量空置或者低效使用嘅工廠大廈。

大家可以想像一下嗰個畫面：以前機器聲不絕於耳嘅工廠大廈，變成咗空空蕩蕩嘅「鐵籠」；以前工人排住隊返工嘅街道，變得冷冷清清。觀塘由繁華嘅工業重鎮，變成咗一個充滿空置工廈嘅「沉睡區域」。

呢個情況一直持續到2001年，政府終於推出咗一個關鍵政策——「工業用地改作商業用途」政策，容許觀塘等舊工業區嘅工業大廈重建或者改裝為商業用途。呢個政策，就成為咗後來 THE ICON 能夠出現嘅政策基礎。

#### 現場觀察重點

- 對比觀塘道兩旁新建商廈與舊式工廈的外觀差異
- 留意舊式工廈地下店舖可能仍保留的工業用途痕跡（如五金舖、印刷廠）
- 觀察空置或改裝中的工廈，思考其未來發展可能性

#### 歷史故事

1990年代，隨著香港製造業北移，觀塘工業區逐漸式微，大量工廠大廈空置或低效使用。曾經機器聲不絕於耳嘅工廠大廈，變成空空蕩蕩嘅空間；曾經工人排住隊返工嘅街道，變得冷冷清清。觀塘由繁華嘅工業重鎮，變成咗一個充滿空置工廈嘅「沉睡區域」。直到2001年，政府推出「工業用地改作商業用途」政策，容許觀塘等舊工業區嘅工業大廈重建或改裝為商業用途，先至為觀塘嘅重生帶嚟轉機。呢個政策成為咗後來 THE ICON 能夠出現嘅政策基礎，亦標誌住觀塘由工業區走向商業區嘅起點。

---

### 第四站：THE ICON 的誕生——由工廈到商廈的蛻變

好，我哋轉返身望住 THE ICON。而家我同大家講下呢座大廈點樣「出世」。

2000年代中後期，恆基兆業地產有限公司收購咗觀塘道320至322號原本嘅工業大廈地段，計劃將佢重建為一座現代化嘅商業大廈。

大家試諗下，要將一塊工業用地變成商業用地，中間涉及嘅唔單止係拆樓起樓咁簡單。發展商要向城市規劃委員會申請改變土地用途，要符合新嘅建築條例同消防安全標準，要重新規劃交通配套……每一個步驟，都反映咗香港城市規劃制度嘅嚴謹同複雜。

大約喺2010至2012年間，THE ICON 正式動工興建。到咗大約2013至2014年，大廈落成入伙，正式為觀塘道提供現代化嘅寫字樓空間。

THE ICON 嘅出現，唔係一座孤立嘅建築，而係觀塘道沿線「工業轉商業」重建浪潮嘅其中一個重要項目。佢同周邊嘅新建商業項目一齊，逐步改變咗觀塘嘅城市面貌。

#### 現場觀察重點

- 注意大廈入口的商業化設計（如門廊、大堂設計），與傳統工廈的貨物出入口形成對比
- 觀察大廈周邊的交通配套，包括巴士站、小巴站等，反映商業區對交通的需求
- 留意大廈低層的零售空間，這是現代商業大廈混合用途模式的特徵

#### 歷史故事

2000年代中後期，恆基兆業地產有限公司收購觀塘道320-322號原工業大廈地段，計劃重建為現代化商業大廈。將工業用地轉為商業用地，涉及向城市規劃委員會申請改變土地用途、符合新建築條例同消防安全標準、重新規劃交通配套等複雜程序。約2010至2012年間，THE ICON 正式動工興建；約2013至2014年落成入伙，為觀塘道提供現代化寫字樓空間。THE ICON 嘅誕生，係觀塘道沿線「工業轉商業」重建浪潮嘅重要項目之一，見證咗呢片土地由工業生產空間到商業服務空間嘅蛻變。

---

### 第五站：「起動九龍東」與 CBD2 的願景

各位團友，講到呢度，我要同大家介紹一個好重要嘅政策——「起動九龍東」計劃。

2012年，政府正式啟動「起動九龍東」計劃，將觀塘、九龍灣同啟德發展區定位為香港第二個商業核心區，簡稱「CBD2」。大家可能會問：香港已經有中環做CBD，點解仲要搞多個CBD2？

原因好簡單：中環嘅商業用地已經接近飽和，租金越來越貴，好多企業負擔唔起。政府需要開拓新嘅商業核心區，提供更多寫字樓空間，分流中環嘅壓力。而九龍東，憑住大量可重建嘅舊工業用地同埋啟德發展區嘅大片新土地，就成為咗最理想嘅選擇。

THE ICON 作為觀塘道沿線嘅新建商業大廈，正好受惠於呢個政策。佢提供嘅現代化寫字樓空間，吸引咗唔少企業由中環、東區搬過嚟，亦都為區內創造咗新嘅就業機會。

由2010年代後期到而家，觀塘道一帶持續有新嘅商業項目落成。THE ICON 同周邊嘅重建項目，共同塑造咗觀塘嘅新商業面貌。

#### 現場觀察重點

- 觀察 THE ICON 周邊的交通配套（港鐵觀塘站、巴士站、小巴站），思考商業核心區對交通基建的需求
- 留意觀塘道沿線其他新建商業項目，感受 CBD2 的發展規模
- 注意街道行人流量與組成，與工業時代相比的變化

#### 歷史故事

2012年，政府正式啟動「起動九龍東」計劃，將觀塘、九龍灣及啟德發展區定位為香港第二個商業核心區（CBD2）。中環商業用地接近飽和，租金高企，政府需要開拓新商業核心區分流壓力。九龍東憑住大量可重建嘅舊工業用地同啟德發展區嘅大片新土地，成為最理想嘅選擇。THE ICON 作為觀塘道沿線新建商業大廈，受惠於此政策，提供嘅現代化寫字樓空間吸引唔少企業由中環、東區搬過嚟，為區內創造新就業機會。2010年代後期至今，觀塘道一帶持續有新商業項目落成，THE ICON 與周邊重建項目共同塑造觀塘新商業面貌。

---

### 第六站：新舊並存的城市風景

最後，我想請大家做一個觀察練習。

請你哋沿住觀塘道望過去，你會見到一個好特別嘅城市風景：一邊係 THE ICON 呢啲新建嘅玻璃幕牆商業大廈，另一邊仲有唔少舊式工業大廈，有啲甚至仲有印刷廠、五金舖喺度運作。新與舊、商業與工業，就咁並存喺同一條街道上面。

呢個就係觀塘最獨特嘅地方。佢唔係一刀切咁將所有舊嘢拆晒起過晒新嘢，而係經歷緊一個漸進式嘅轉型。有啲工廈重建做商廈，有啲改裝做文創空間或者迷你倉，有啲仲保留住工業用途。

呢種新舊並存嘅狀態，有人覺得係混亂，有人覺得係活力。但無論如何，佢記錄住觀塘由工業區走向商業核心區嘅完整歷史軌跡。而 THE ICON，就係呢段歷史軌跡上面一個好重要嘅里程碑。

#### 現場觀察重點

- 沿觀塘道遠眺，觀察新建商廈與舊式工廈並存的城市天際線
- 留意舊工廈的不同再利用模式（重建商廈、改裝文創空間、保留工業用途）
- 思考新舊並存對城市景觀與社區活力的影響

#### 歷史故事

觀塘嘅城市轉型並非一刀切嘅推倒重來，而係一個漸進式嘅過程。由1950年代嘅工業新市鎮，經歷1960至80年代嘅製造業黃金期、1990年代嘅工業北移、2001年嘅工業用地轉商業政策、2010至2014年 THE ICON 嘅重建與落成，到2012年至今嘅「起動九龍東」與 CBD2 發展——每一個階段都喺呢條街道上面留下咗印記。有啲工廈重建做商廈，有啲改裝做文創空間或者迷你倉，有啲仲保留住工業用途。呢種新舊並存嘅狀態，記錄住觀塘由工業區走向商業核心區嘅完整歷史軌跡，而 THE ICON 就係呢段軌跡上面一個重要嘅里程碑。

### 結語

各位團友，今日我哋由 THE ICON 呢座建築出發，回顧咗觀塘由1950年代嘅工業新市鎮，經歷製造業黃金期、工業北移、政策轉型，到今日成為香港第二個商業核心區嘅完整歷程。

下次當你經過觀塘道，見到 THE ICON 嗰幅閃閃生光嘅玻璃幕牆，希望你會記得：喺呢幅玻璃幕牆嘅背後，曾經係無數工廠工人嘅汗水同機器聲，曾經係香港製造業嘅驕傲。而今日，佢以另一種面貌，繼續書寫住觀塘嘅城市故事。

多謝大家，我哋嘅導賞到此結束。如果有任何問題，歡迎而家提出討論。
