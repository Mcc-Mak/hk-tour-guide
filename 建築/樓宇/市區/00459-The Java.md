## 二、歷史脈絡與建築特色

### 建築風格與特色

The Java 屬現代主義建築風格，外觀簡潔，注重功能性設計。建築採用鋼筋混凝土結構，符合香港現代住宅樓宇的標準設計模式。其設計特點體現「形式跟隨功能」的現代主義原則——立面以實用為主，沒有過多裝飾性元素，反映当代香港住宅建築的典型特徵。

在建築社區脈絡方面，The Java 位於渣華道傳統社區，周邊保留部分戰後建築及歷史街區肌理，體現北角區新舊建築並存的城市景觀特徵。該建築的出現，屬於北角區由傳統舊區向現代化住宅社區轉型脈絡的一部分，取代了之前的舊建築，成為城市更新過程中的產物。

### 歷史事件與背景

#### 戰前北角發展期

- 1919年：渣華道（Java Road）通車命名，名稱源自荷屬東印度爪哇島，反映當時香港與東南亞貿易往來頻繁。渣華道為北角早期主要幹道之一，連接英皇道與電氣道。
- 1930年代：北角一帶逐步從郊野地帶發展為住宅及工業混合區。香港電燈公司於北角設有發電廠（位於今城市花園一帶），帶動該區發展。渣華道沿線開始出現低層住宅及商舖建築。

#### 戰後重建與人口增長期

- 1945-1950年代：二戰結束後，大量內地移民湧入香港，北角成為人口密集的住宅區之一。渣華道沿線出現大量戰後唐樓及簡陋住宅，以應付急增的住屋需求。
- 1950-1960年代：北角區持續發展，渣華道一帶逐漸形成成熟的社區網絡，包括街市、學校及商舖。該時期建築多以實用為主，採用鋼筋混凝土結構，外觀簡約。

#### 現代化與城市更新期

- 1970-1980年代：北角區進入城市更新階段，部分舊式唐樓被重建為較高層的住宅大廈。渣華道沿線建築密度增加，地產發展商開始收購舊樓重建。
- 1990年代至今：北角渣華道一帶持續有重建項目。The Java 為較近期發展的私人住宅項目，反映北角區由傳統舊區向現代化住宅社區轉型的趨勢。該建築採用現代建築設計，配合區內城市更新步伐。

各位參加者，大家好。歡迎參加今日嘅北角建築導賞團。我哋今日企喺渣華道同埋電氣道交界附近，眼前呢一座現代化嘅住宅大廈，就係今日導賞嘅主角——The Java，渣華道98號。

大家望一望呢座樓，可能會覺得：「呢座好似同出面好多新建築差唔多喎，有咩特別值得講呢？」其實每一座建築，都係一個社區發展嘅見證。The Java 雖然唔係古蹟，但佢企喺渣華道呢條有百年歷史嘅街道上面，背後承載嘅係成個北角區由荒野變成今日繁華社區嘅故事。等我慢慢同大家講。

### 第一站：渣華道嘅名字密碼

#### 現場觀察重點

> 請大家低頭望一望腳下嘅街道名牌——「渣華道 Java Road」。再抬頭望望四周，英皇道喺嗰邊，電氣道喺另一邊，渣華道就係連接兩者嘅其中一條主要幹道。

#### 歷史故事

「渣華道」呢個名，大家有冇諗過係點嚟嘅？其實「渣華」就係「Java」嘅粵語音譯，即係而家印尼嘅爪哇島。

點解香港會有一條街用印尼嘅島嶼嚟命名呢？呢個要追溯到香港開埠以嚟同東南亞嘅貿易關係。十九世紀末到二十世紀初，香港作為自由港，同東南亞各地嘅貿易往來非常頻繁。爪哇島當時係荷屬東印度嘅一部分，盛產咖啡、糖同埋香料，呢啲商品好多都經香港轉口運去世界各地。所以港英政府喺開發北角一帶嘅時候，就用咗「Java」嚟為呢條新道路命名，紀念呢段貿易歷史。

渣華道係北角早期開發嘅主要道路之一。大家如果翻查舊地圖，會見到北角一帶喺十九世紀末基本上仲係郊野，有啲村落同埋農田。去到二十世紀初，政府開始喺度起路、填海，渣華道就係喺呢個時期開通嘅。雖然確實嘅通車年份仲需要進一步查證政府憲報嘅原始紀錄，但可以肯定嘅係，渣華道見證住北角由郊野地帶逐步發展成為市區嘅整個過程。

### 第二站：北角發電廠與工業萌芽

#### 現場觀察重點

> 請大家望向城市花園嗰個方向。而家我哋見到嘅係高層住宅同埋商場，但喺好耐好耐之前，呢一帶曾經有一座好重要嘅工業設施。

#### 歷史故事

講到北角嘅早期發展，一定要提香港電燈公司嘅北角發電廠。喺1919年，港燈喺北角起咗一座發電廠，位置大約就喺而家城市花園一帶。呢座發電廠對北角嘅發展起到好關鍵嘅作用。

點解咁講呢？發電廠起好之後，第一，佢提供咗穩定嘅電力供應，令到北角一帶可以發展工業同埋住宅；第二，發電廠本身需要大量工人，帶動咗人口流入；第三，圍繞發電廠周邊，慢慢形成咗一個社區網絡，有住宅、有商舖、有街市。

去到1930年代，北角已經由一個偏僻嘅郊野地方，逐步發展成為住宅同工業混合嘅區域。渣華道沿線開始出現一啲低層嘅住宅同埋商舖建築。嗰陣時嘅北角，雖然唔及而家咁繁華，但已經有咗一個社區嘅雛形。

### 第三站：戰後移民潮與北角變遷

#### 現場觀察重點

> 請大家留意一下渣華道兩旁嘅建築。你哋會發現一個有趣嘅現象：有啲樓好新，有啲樓就明顯有番一定年紀。呢種新舊建築並存嘅景觀，正正反映咗北角區嘅發展歷程。

#### 歷史故事

1945年，第二次世界大戰結束。戰後嘅香港面對一個好大嘅變化——大量內地移民湧入。北角因為地理位置方便，又有一定嘅基礎設施，成為咗好多移民落腳嘅地方。

喺1940年代尾到1950年代，渣華道沿線出現咗大量嘅戰後唐樓同埋簡陋住宅。嗰陣時嘅建築，主要係為咗應付急增嘅住屋需求，所以設計好簡單，以實用為主。好多都係幾層高嘅唐樓，地下做商舖，上面幾層做住宅。

去到1950至1960年代，渣華道一帶逐漸形成一個成熟嘅社區網絡。街市、學校、茶樓、冰室、雜貨舖……一個社區需要嘅嘢，呢度都有。嗰段時間嘅建築，多數採用鋼筋混凝土結構，外觀簡約，反映咗嗰個年代「實用至上」嘅建築理念。

大家可以想像一下，嗰陣時嘅渣華道，同而家好唔同。街道兩旁係一排排嘅唐樓，地下係各式各樣嘅小店，街坊出入打招呼，細路喺街邊玩，小販推住車賣魚蛋粉……呢種充滿人情味嘅社區生活，係好多老一輩北角居民嘅集體回憶。

### 第四站：城市更新與 The Java 嘅出現

#### 現場觀察重點
