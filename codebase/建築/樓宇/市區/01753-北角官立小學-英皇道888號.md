## 二、歷史脈絡與建築特色

### 建築風格與特色

北角官立小學的建築屬於**戰後功能主義**風格，具有1950年代香港政府學校建築的典型特徵。此類建築反映了1950年代香港政府的實用主義建築方針——在有限資源及迫切需求下，以最經濟高效的方式建造符合基本教學需求的教育設施。建築設計強調功能性、耐久性及可複製性，多所同期興建的官立學校均採用類似的標準化設計模式。

| 特徵 | 描述 |
|------|------|
| **結構** | 鋼筋混凝土框架結構，為戰後香港標準建築工法 |
| **立面設計** | 簡潔幾何線條，外牆以實用為主，裝飾極少 |
| **窗戶設計** | 大面積窗戶排列，確保教室自然採光及通風 |
| **走廊佈局** | 採用長走廊式佈局，教室沿走廊兩側或單側排列 |
| **樓層設計** | 多層設計（約4-6層），以最大化用地效率 |
| **屋頂** | 平頂設計，符合現代主義建築特徵 |
| **材料** | 以混凝土、磚及鋼材為主要建材，注重耐久性 |

### 歷史事件與背景

#### 戰後教育擴張期

- 1954年：北角官立小學正式創校，為戰後香港政府大規模擴展官立教育體系的重要一環。二戰結束後，大量人口從中國內地湧入香港，北角區因鄰近海岸線及工業發展，成為主要人口聚居地之一。政府為應對激增的學齡兒童人口，在港九各區興建官立小學，北角官立小學即在此背景下設立。
- 1950年代中後期：學校全面投入運作，採用上午及下午兩班制（AM/PM制），以最大化學額供應。此時期北角區被稱為「小上海」，大量上海移民聚居於此，學校學生背景多元，反映當時北角社區的移民文化特色。

#### 社區發展期

- 1960年代：北角區持續城市化發展，英皇道沿線住宅及商業設施日趨密集。北角官立小學作為區內主要官立小學之一，承擔重要的基礎教育職能。學校服務範圍覆蓋北角及鄰近炮台山一帶。
- 1970年代：香港實施免費強迫教育，官立小學體系進一步擴展。北角官立小學在此時期繼續為區內適齡學童提供免費小學教育，學額需求持續旺盛。
- 1980年代：北角區人口結構逐漸轉變，隨著新一代本地出生人口增加及舊區重建，學校服務的社區面貌亦隨之變化。學校在建築設施上可能進行了局部翻新及設施升級，以配合現代化教學需求。

#### 現代發展期

- 1990年代：教育改革深化，學校逐步引入資訊科技教學設施。建築物可能經歷結構評估及必要的維修加固工程，以符合更新後的建築安全標準。
- 2000年代：香港教育制度實施重大改革，包括取消學能測驗、推行新課程等。北角官立小學作為官立學校，跟隨教育局政策調整教學方向。學校建築持續維護保養，確保安全及教學環境質素。
- 2010年代至今：學校繼續在英皇道888號原址運作，為北角區提供優質官立小學教育。學校積極推動STEM教育及全方位學習，建築設施配合現代教育需求持續更新。

## 五、導賞員現場講稿

### 開場白

各位團友，大家好！歡迎來到今日的東區歷史建築導賞團。我們現在站在車水馬龍的英皇道上，大家不妨看看我身旁這個門牌——英皇道888號。這裡就是今日導賞的主角：北角官立小學。

這座大約在1954年建成的學校，看起來也許平平無奇，但它見證了香港戰後教育的擴張、北角社區的變遷，以及幾代香港人在這裡成長的足跡。接下來，我會帶大家從建築外觀到歷史故事，一起細讀這座建築背後的點滴。

### 各站點

### 北角官立小學

#### 現場觀察重點

大家不妨退後幾步，抬頭望一望這座建築的外觀。你們看到甚麼？是不是覺得它跟我們平時在舊區見到的戰前洋房或唐樓很不一樣？沒錯，這座大約在1954年建成的學校，展現的是典型的「戰後功能主義」或「國際風格」。

大家可以留意幾個建築重點：

**第一，結構與材料。** 它的結構是鋼筋混凝土框架，這在戰後的香港是最標準、最快速的建築工法。主要建材為混凝土、磚及鋼材，注重耐久性。

**第二，窗戶設計。** 看看那些窗戶，是不是排列得非常整齊，而且面積很大？這不是單純為了美觀——在沒有冷氣的年代，大面積的窗戶能確保教室有充足的自然採光和通風，這對學生的學習環境至關重要。

**第三，立面與佈局。** 它的外牆沒有多餘的裝飾，線條簡潔，採用平頂設計，內部是長走廊式的佈局，教室沿著走廊排列。多層設計（約4至6層）以最大化用地效率。

這種設計反映了1950年代香港政府一種很務實的態度：在資源有限、需求迫切的情況下，用最經濟、最高效的方式，建造出符合教學基本需求的教育設施。這套設計圖紙甚至是可以複製的，當年港九各區新建的官立小學，很多都採用了類似的標準化設計。

#### 歷史故事

**小上海與戰後教育擴張**

看完了建築外觀，我們來聽聽這所學校背後的故事。為甚麼政府會在1954年急急忙忙在這裡建一所小學呢？

二戰結束後，大量人口從內地湧入香港。北角因為鄰近海岸線，又有工業發展，成了主要的人口聚居地。當時的北角有個花名，叫「小上海」，因為這裡聚居了大量上海移民，他們帶來了上海理髮店、上海菜館，甚至連這裡的學生背景都非常多元，反映了當時北角社區獨特的移民文化特色。

人口多了，學齡兒童自然就多。當時的政府為了應對激增的學童，開始大規模擴展官立教育體系，北角官立小學就是在這個背景下誕生的。它就像一場及時雨，接住了北角及炮台山一帶一代又一代的小朋友。

**從上下午班到現代教育**

大家可能會問，當年學位這麼緊張，一間學校怎麼夠用呢？這就要提到香港教育史上一個很特別的制度——上下午班制，也就是我們常說的AM和PM制。

北角官立小學全面投入運作後，就實行了這個制度。同一間教室，上午一批學生上課，下午換另一批學生，這樣就能把學額供應最大化。很多老一輩的香港人，都有過讀上午校或下午校的集體記憶。

到了1970年代，香港實施免費強迫教育——1971年開始推行免費小學教育，1978年全面實施免費及強迫九年教育。官立小學體系進一步擴展，這裡的學額需求依然旺盛。

再後來，到了2000年代，大家還記得「學能測驗」嗎？那個讓很多小六學生頭痛的考試在1999年宣佈取消，2000年起逐步廢除，學校又跟隨教育局推行新課程。

時至今日，這座已經七十歲的建築依然在原址運作，裡面的小朋友可能正在上STEM課程，做著現代化的科學實驗呢。建築物的設施也隨著時代不斷更新，配合現代教育的需求。

### 結語

各位團友，北角官立小學目前並沒有被古物古蹟辦事處列為法定古蹟或評級歷史建築。它看起來平平無奇，甚至有點舊。但它的價值，不在於雕樑畫棟，而在於它是一塊活化石，見證了香港戰後教育的擴張、北角社區的變遷，以及幾代香港人在這裡成長的足跡。

下次當你經過英皇道888號，不妨再抬頭看看這些大窗戶和長走廊，想像一下裡面曾經傳出的瑯瑯讀書聲，那就是這座建築最動人的故事。

好，我們在這裡稍作停留拍照，五分鐘後我們前往下一個景點。
