## 二、歷史脈絡與建築特色

### 建築風格與特色

One Harbour Gate 採用現代主義商業建築風格，最顯著的設計特徵為「雙子塔」佈局——由東座與西座兩座相連的商業大廈組成。建築外牆全面採用玻璃幕牆系統，不僅讓室內空間享有無遮擋的維多利亞港海景，更在外觀上形成巨大的鏡面效果，將維港的天光雲影倒映於建築表面，使龐大的建築體量顯得輕盈而富現代感。

基座部分運用石材與金屬元素，展現甲級寫字樓應有的專業氣派。東、西兩座各自設有獨立的升降大堂，於基座相連，既共享建築設施，又保障各企業租戶的私密性與安保需求。建築設計由本地著名的王董建築師事務所擔任，發展商為會德豐地產。

### 歷史事件與背景

#### 紅磡灣填海與都市發展期

- 1990年代：香港政府展開紅磡灣填海工程，紅鸞道一帶的土地由此形成，將紅磡原有海岸線向外推進，為日後的商業與住宅發展提供土地資源。
- 2000年代：紅磡灣填海區逐漸轉型，城市規劃委員會將紅鸞道一帶劃為商業及酒店用途，帶動黃埔一帶的商業化延伸發展。

#### One Harbour Gate 建設與落成期

- 2013年：會德豐地產正式宣佈發展紅鸞道18號商業項目，並命名為 One Harbour Gate，由王董建築師事務所擔任建築設計，項目正式動工。
- 2016年：One Harbour Gate 正式落成入伙。建築由兩座相連的商業大廈（東座及西座）組成，採用現代主義風格及全玻璃幕牆設計，成為紅磡臨海的新商業地標。

#### 企業總部進駐與現代發展期

- 2017年：宏利人壽保險（國際）有限公司宣佈以約 45 億港元購入 One Harbour Gate 西座全幢，作為其香港區總部之一，創下當時九龍區最大額的單一商廈成交紀錄。
- 2018年至今：One Harbour Gate 作為甲級寫字樓，持續吸引跨國企業、金融機構及專業服務公司進駐，進一步鞏固紅磡灣區作為九龍東與核心商業區交匯處的商業樞紐地位。

## 五、導賞員現場講稿

### 開場白

各位團友，大家好！歡迎參加今日的香港樓宇導賞團。我哋現在站立的位置，是九龍紅磡紅鸞道18號。請大家稍微抬頭，望一望眼前這兩座氣勢恢宏、外牆閃爍著維港波光的商業大廈——這就是我們今日的主角：One Harbour Gate（維港中心）。

這座建築不僅是紅磡臨海的新商業地標，更承載了一段從汪洋到黃金地段的滄海桑田故事。接下來，我會帶大家走過三個導賞站點，從遠觀到近賞，一起感受這座建築的設計美學與歷史底蘊。

### 紅磡灣海濱長廊遠眺點

#### 現場觀察重點

大家可以先留意一下建築的整體外觀。One Harbour Gate 於2016年正式落成入伙，由本地著名的王董建築師事務所設計，會德豐地產發展。建築採用了典型的現代主義商業風格，最搶眼的是「雙子塔」的設計——分為東座和西座兩座相連的商業大廈。大家看看那面全玻璃幕牆，這不僅讓大廈內部能享有無遮擋的維港海景，在外觀上也像一面巨大的鏡子，將維多利亞港的天光雲影倒映出來，令這座龐大的建築顯得輕盈而現代。

#### 歷史故事

不過，大家又是否知道，我們現在腳踏的這片土地，其實在幾十年前還是汪洋一片？

讓我們把時間推回1990年代。當時香港政府展開了大規模的紅磡灣填海工程，紅鸞道一帶的土地就是這樣「填海得來」的。這項工程將紅磡原有的海岸線大幅向外推進。到了2000年代，城市規劃委員會將這片新填海區劃為商業及酒店用途，正式帶動了黃埔一帶的商業化延伸發展。所以，One Harbour Gate 不僅是一座建築，它更是紅磡灣從海洋蛻變成現代商業樞紐的歷史見證。

### One Harbour Gate 基座廣場及入口大堂

#### 現場觀察重點

我們再看看大廈的基座和入口設計。作為區內的甲級寫字樓，One Harbour Gate 的大堂空間寬敞，石材與金屬元素的運用展現了跨國企業所需的專業氣派。這裡的規劃非常清晰，東、西兩座各自有獨立的升降大堂，卻又在基座相連，既能共享建築設施，又能保障各企業的私密性與安保需求。請大家注意大堂入口的比例與層次感——高聳的樓底、精確的石材拼接，都是甲級商廈的設計語彙。

#### 歷史故事

說到這裡，不得不提一件轟動地產界的大事。One Harbour Gate 在2016年落成後，很快就吸引了跨國巨企的目光。去到2017年，宏利人壽保險（國際）有限公司宣佈，以約45億港元的天價，買入了西座全幢，作為其香港區總部之一。

各位團友，45億港元這個數字，在當時創下了九龍區最大額的單一商廈成交紀錄！這宗交易不僅證明了發展商的眼光和建築的質素，更具有指標性的意義——它標誌著紅磡灣區已經具備了與傳統核心商業區（如中環、尖沙咀）看齊的實力，成功吸引頂級金融機構進駐。

### 紅鸞道與黃埔花園交界處

#### 現場觀察重點

現在我們退後一步，從這個交界處回望整個建築群。大家可以觀察 One Harbour Gate 與周邊環境的關係——前方是開闊的維港海景，後方緊接黃埔花園等住宅與商業社區。這個位置正好展現了紅磡灣區作為九龍東與核心商業區交匯處的地理優勢。建築的雙子塔輪廓在這個角度更為分明，與海面的倒影相映成趣。

#### 歷史故事

時至今日，由2018年開始，One Harbour Gate 持續吸引著各國跨國企業、金融機構及專業服務公司在此匯聚。它就像一道「海港之門」（Harbour Gate），穩守著九龍東與核心商業區交匯處的商業樞紐地位。

從1990年代的填海工程，到2000年代的規劃變更，再到2013年動工、2016年落成、2017年的天價成交，One Harbour Gate 的故事其實就是香港城市發展生命力的最佳寫照——不斷填海造地、不斷更新城市功能、不斷吸引國際資本。

### 結語

下次當大家乘搭天星小輪或者在海旁散步，遠遠看到這對閃亮的雙子塔時，不妨想起這片土地從海底升起，再到成為45億天價地標的故事。這就是香港城市發展生命力的最佳寫照。
