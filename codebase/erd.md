# 實體關係圖 (ERD)

> 本專案以檔案系統為資料儲存，以下為各資料實體之間的關聯。

## 實體關係

```
┌───────────────────┐         ┌───────────────────────┐
│  specbase/         │  links  │  .crewai/矩陣/         │
│  導賞目標建築矩陣.md │────────→│  **/*.md (TOC 子檔案)  │
│  (根索引檔)         │         │                       │
└───────────────────┘         └───────────┬───────────┘
                                          │
                                          │ 1:N (編號 N)
                                          ▼
┌───────────────────┐         ┌───────────────────────┐
│  codebase/建築/    │←────────│  矩陣 row (單棟建築)   │
│  NN-名稱.md        │ 生成連結  │                       │
│  (導賞手冊)         │────────→│                       │
└───────────────────┘ 更新狀態  └───────────┬───────────┘
                                          │
                                          │ 資料來源
                                          ▼
                              ┌───────────────────────┐
                              │  .crewai/data/*.json  │
                              │  (開放資料原始檔)       │
                              └───────────────────────┘
```

## 實體定義

### Entity: MatrixRow（矩陣列）

| 屬性 | 鍵 | 說明 |
| :--- | :---: | :--- |
| N | PK | 子檔案內獨立編號 |
| category | | 導賞專案類別 |
| name | | 建築中文名稱 |
| address | | 建築中文地址 |
| credibility | | 歷史檔案可信性等級 |
| completion | | 工作進度 Emoji 狀態 |
| link | FK | 指向 Handbook 檔案路徑 |
| _matrix_file | | 所属子檔案路徑（複合鍵要素） |

### Entity: Handbook（導賞手冊）

| 屬性 | 鍵 | 說明 |
| :--- | :---: | :--- |
| file_path | PK | `codebase/建築/{subdir}/NNNNN-名稱.md` |
| n_id | FK | 對應矩陣編號 N（零填補 5 位） |
| subdir | | 子目錄（法定古蹟 / 樓宇/市區 / 樓宇/新界） |
| content | | Markdown 內容（六段式結構） |
| model | | 生成時使用的 LLM 模型標籤 |

### Entity: OpenData（開放資料）

| 屬性 | 鍵 | 說明 |
| :--- | :---: | :--- |
| source | PK | `CSDI` / `RVD_Urban` / `RVD_NT` |
| name_zh | | 建築中文名稱 |
| name_en | | 建築英文名稱 |
| address_zh | | 建築中文地址 |
| address_en | | 建築英文地址 |

## 關聯

| 關聯 | 基數 | 說明 |
| :--- | :--- | :--- |
| MatrixRow → Handbook | 1:1 | 每棟建築生成一份手冊；矩陣 link 欄位指向手冊路徑 |
| OpenData → MatrixRow | 1:N | 一筆開放資料可對應一列矩陣（21 棟 CSDI/RVD 重複已從 RVD 排除） |
| 根索引 → MatrixFile | 1:N | `specbase/導賞目標建築矩陣.md` 連結至 3 個矩陣子檔案 |
