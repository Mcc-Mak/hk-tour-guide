## 二、歷史脈絡與建築特色

### 建築風格與特色

彌敦道大樓屬戰後九龍典型商住混合樓宇，其建築風格特徵如下：

| 特徵 | 描述 |
|------|------|
| **建築風格** | 戰後實用主義，帶現代主義簡約元素 |
| **結構** | 鋼筋混凝土結構 |
| **樓層配置** | 地下商舖、樓上住宅（典型「下舖上居」格局） |
| **立面設計** | 簡潔立面，功能性窗戶排列，少裝飾 |
| **建築材料** | 混凝土、水磨石（常見於地下舖面，待實地確認） |
| **街道關係** | 緊貼行人路建築線，形成連續街牆 |

此類建築反映了1960年代香港戰後重建的實用導向，以經濟高效的方式滿足居住與商業需求，是九龍城市化進程中的重要建築類型。現代主義建築強調「形式追隨功能」，反對無謂的裝飾，此理念在戰後香港的商住樓宇中得到廣泛應用——並非因為建築師刻意追求前衛，而是因為戰後重建的迫切需求與有限資源，令實用主義成為最自然的選擇。

### 歷史事件與背景

#### 彌敦道開闢與早期發展期

- 1909年：港府將九龍半島主要幹道「羅便臣道」正式更名為「彌敦道」，以紀念時任港督彌敦爵士（彌敦爵士於1904年上任），此為彌敦道沿線發展之起點。
- 1906年：彌敦道延伸至界限街以北（確切年份約為1906至1911年間，尚待工務局年報確認），九龍半島交通網絡逐步成形，帶動沿線土地發展。
- 1920年代：九龍半島城市化加速，彌敦道沿線陸續興建低層商住樓宇，太子至旺角一帶逐漸形成商業街區雛形。

#### 日佔時期與戰後重建期

- 1941年：香港淪陷，進入三年零八個月日佔時期（1941年12月25日至1945年8月15日），九龍區基礎設施遭受破壞，彌敦道沿線部分建築損毀或失修。
- 1945年：香港重光，戰後人口急劇膨脹，九龍區住房需求迫切，推動彌敦道沿線重建。
- 1950年代：戰後重建高峰期，大量戰前唐樓被拆卸重建為四至六層高的商住樓宇，彌敦道509-511A號地段所在的太子／旺角段成為重建熱點。

#### 現代化發展與建築成形期

- 1960年代：彌敦道509-511A號地段上之「彌敦道大樓」推測於此時期建成，屬戰後第二代商住樓宇，採用鋼筋混凝土結構，樓高數層，地下為商舖、樓上為住宅單位，反映當時九龍典型商住混合發展模式。
- 1967年：香港發生社會騷亂（六七暴動，5月至12月），彌敦道作為九龍主幹道受影響，沿線商業活動一度受阻。
- 1970年代：彌敦道沿線持續發展，地下鐵路修正早期系統（觀塘綫及荃灣綫）於1975年動工、1979年通車，太子站及旺角站建設帶動該區商業繁榮，彌敦道大樓所在地段價值上升。

#### 都市更新與保育關注期

- 1980年代：彌敦道沿線高層商廈及商場陸續落成，509-511A號一帶保留較低層數的舊式商住樓宇，形成新舊建築並存的城市景觀。
- 2000年代：市區重建局（2001年成立）開始關注旺角／太子一帶舊樓狀況，部分戰後樓宇被納入重建範圍，彌敦道大樓因具一定建築年代與街區特徵，被納入樓宇導賞團路線。
- 2010年代至今：彌敦道大樓作為香港樓宇導賞團的參觀點之一，向公眾展示戰後九龍商住樓宇的建築風格與社區歷史，成為認識旺角城市發展的實物案例。

### 開場白

各位團友，大家好！歡迎參加今日嘅香港樓宇導賞團。我哋而家企喺嘅位置，就係九龍旺角同太子交界——彌敦道509至511A號門前。請大家先望一望眼前呢棟樓宇，佢唔似隔籬嗰啲高聳入雲嘅商場同商廈咁耀眼，但佢靜靜咁企喺度，見證住成條彌敦道超過半個世紀嘅變遷。

呢棟就係我哋今日要介紹嘅「彌敦道大樓」。佢唔係乜嘢豪宅宮殿，而係一棟好典型、好地道嘅戰後商住混合樓宇。但正正就係呢份「典型」，令佢成為我哋認識香港戰後城市發展嘅一個活生生嘅教材。
