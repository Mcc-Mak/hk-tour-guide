## 二、歷史脈絡與建築特色

### 建築風格與特色

寶馬花園屬於1990年代香港典型的私人住宅建築，展現現代主義設計理念，具有以下建築特徵：

| 特徵 | 描述 |
|------|------|
| 建築風格 | 現代主義，強調功能性與簡潔線條 |
| 結構形式 | 鋼筋混凝土高層建築 |
| 立面設計 | 簡約外牆設計，採用玻璃窗戶及露台 |
| 單位布局 | 標準化住宅單位，以實用面積最大化為原則 |
| 公共設施 | 設有基本住宅配套，包括大堂、保安系統及停車位 |
| 環境配合 | 配合馬寶道街道環境，與周邊住宅及商業建築協調 |

建築整體設計反映北角從傳統工商業區向現代住宅區轉型的時代趨勢，提供標準化住宅單位以配合區內中產家庭的居住需求。外牆無多餘裝飾，以功能性為主導，與1990年代香港私人住宅的建築潮流一致。

### 歷史事件與背景

#### 早期北角發展期（1920s–1940s）

- 1921年：香港政府於北角展開填海工程，為該區的工業與住宅發展奠定基礎。馬寶道一帶原為沿海地段，填海後逐步形成街道網絡。
- 1930年代：北角逐漸發展為工業區，區內設有發電廠、船塢及糖廠等設施。馬寶道作為區內街道之一，周邊以工業及倉庫用途為主。
- 1941–1945年：日佔時期，北角地區發展停滯，部分設施遭破壞或徵用。

#### 戰後重建與移民潮（1945–1960s）

- 1945年：二次大戰結束後，北角開始重建。大量人口湧入香港，北角成為新移民的主要聚居地之一。
- 1950年代：大量上海移民湧入北角，該區被稱為「小上海」。馬寶道一帶發展成繁盛的商業街道，設有各式商店、餐廳及娛樂場所。區內人口密集，住宅需求急增，出現多層唐樓及木屋區。
- 1960年代：北角繼續急速發展，馬寶道成為區內重要的商業街道。政府開始規劃改善該區的基礎設施，包括道路擴闊及排水系統改善。

#### 工業轉型與城市更新（1970s–1980s）

- 1970年代：北角工業開始轉型，部分工業用地改為住宅及商業用途。政府推行新市鎮發展計劃，部分北角居民遷往新界，但區內住宅需求仍然殷切。
- 1980年代：隨著香港經濟起飛及製造業北移，北角地區進行城市更新。舊式唐樓及工業建築逐漸被現代化住宅大廈取代。馬寶道一帶的重建計劃陸續展開，為後來的住宅發展項目（包括寶馬花園）創造條件。

#### 現代化發展期（1990s–至今）

- 1990年代：寶馬花園於此時期落成，為馬寶道33號的私人住宅發展項目。該項目反映北角從傳統工商業區向現代住宅區的轉型趨勢。建築採用現代主義設計，提供標準化住宅單位，配合區內中產家庭的居住需求。
- 2000年代：北角持續發展為港島東區的重要住宅及商業樞紐。寶馬花園鄰近港鐵北角站，交通便利，成為區內受歡迎的住宅屋苑之一。
- 2010年代：北角地區進一步活化，馬寶道一帶保留部分傳統商業特色，同時引入現代化零售及餐飲設施。寶馬花園作為區內住宅，受惠於周邊社區設施的持續改善。
- 2020年代至今：寶馬花園維持穩定的住宅用途，所在區域持續發展。北角作為港島東的核心地帶，交通網絡完善，包括港鐵、電車及多條巴士線，連接港島各區及九龍。

#### 歷史故事

企喺馬寶道，大家可能想像唔到，我哋腳下嘅土地，其實有一段好精彩嘅變遷史。

將時間推返去1921年，當時香港政府喺北角展開填海工程。換言之，我哋而家企嘅地方，百年前其實係一片汪洋。填海之後，馬寶道一帶先至慢慢形成街道網絡。

去到1930年代，北角逐漸發展成一個工業區。當時呢度有發電廠、船塢，仲有糖廠。大家可以幻想下，當年呢區空氣入面，可能仲會飄住陣陣製糖嘅甜味，同埋見到發電廠煙囪噴出嘅白煙。

不過，北角最傳奇嘅年代，一定係戰後嘅1950年代。二戰結束之後，大量人口湧入香港，其中有好大批上海移民選擇喺北角落腳。佢哋帶嚟咗資金、技術，仲有上海嘅文化生活習慣。當時嘅北角被稱為「小上海」，而我哋面前嘅馬寶道，就係「小上海」最繁盛嘅商業街道！

街上開滿咗各式各樣嘅上海理髮店、裁縫店、餐廳同埋娛樂場所。夜晚霓虹燈閃爍，街上聽到嘅都係上海話，同埋夜總會傳出嘅爵士樂。嗰種紙醉金迷、充滿活力嘅氣氛，同今日寧靜嘅住宅區有好大對比。

去到1960年代，馬寶道已經成為區內最重要嘅商業街道之一，政府亦開始規劃改善基礎設施，包括道路擴闊同排水系統改善。

### 北角城市轉型觀察點

#### 現場觀察重點

我哋而家企喺馬寶道同英皇道交界，呢度係觀察北角城市轉型嘅最佳位置。請大家向四個方向望一望：

1. **向英皇道東面望**：可以見到現代化嘅住宅大廈同商業大廈，反映北角近年嘅發展面貌。
2. **向英皇道西面望**：留意新舊建築交錯嘅天際線，城市更新嘅痕跡一目了然。
3. **向馬寶道回望**：從呢個角度可以感受到馬寶道由工業區到商業街再到住宅區嘅三重歷史層次。
4. **交通網絡**：留意港鐵北角站嘅出入口、電車路軌同巴士站，體會北角作為港島東交通樞紐嘅地位。

#### 歷史故事

企喺呢個交界點，我哋可以總覽北角百年城市轉型嘅全貌。

1970年代，北角工業開始轉型，部分工業用地改為住宅及商業用途。政府推行新市鎮發展計劃，部分北角居民遷往新界，但區內住宅需求仍然殷切。

去到1980年代，隨住香港經濟起飛及製造業北移，北角地區進行大規模城市更新。舊式唐樓及工業建築逐漸被現代化住宅大廈取代。馬寶道一帶嘅重建計劃陸續展開，為後來嘅住宅發展項目——包括我哋啱啱參觀嘅寶馬花園——創造咗條件。

進入2010年代，北角地區進一步活化，馬寶道一帶保留部分傳統商業特色，同時引入現代化零售及餐飲設施。去到2020年代，寶馬花園維持穩定嘅住宅用途，北角作為港島東嘅核心地帶，交通網絡完善，包括港鐵、電車及多條巴士線，連接港島各區及九龍。

### 結語

所以話，各位團友，寶馬花園唔單止係一棟1990年代嘅現代主義住宅咁簡單。佢企喺度，就好似一本立體嘅歷史書，記錄住北角由海床變工業區，再變成繁華嘅「小上海」，最後蛻變成現代化住宅區嘅百年故事。

我哋今日行過嘅馬寶道，每一塊地磚下面都沉睡住唔同年代嘅記憶——1920年代嘅填海工程、1930年代嘅糖廠甜香、1950年代「小上海」嘅霓虹燈光、1980年代城市更新嘅塵土，同埋1990年代寶馬花園拔地而起嘅鋼筋混凝土。呢一切嘅疊加，就係我哋今日所見所行嘅北角。

下次大家行過馬寶道，不妨抬頭望一望寶馬花園，感受一下呢度曾經有過嘅時代變遷。歷史唔單止留喺博物館入面，佢就喺我哋嘅腳下，喺我哋嘅身邊，等我哋去發現同感受。

多謝大家嘅聆聽，我哋下一個導賞點見！
