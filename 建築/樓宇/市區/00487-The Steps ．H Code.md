## 二、歷史脈絡與建築特色

### 建築風格與特色

The Steps · H Code 為一座現代簡約工業風格之商業大廈，由著名建築師事務所巴馬丹拿集團（P&T Group，前身為公和洋行）設計，基匯資本開發。建築最為矚目的設計特徵為「階梯式」露台——每一層的露台逐層向後退縮，形成一級一級的視覺效果，直接致敬砵典乍街（石板街）的地理特徵與石階地形。建築外牆大量採用玻璃幕牆與金屬元素，營造現代都市感之餘，亦令室內外空間產生視覺連貫性。

大廈內部引入餐飲、零售及創意辦公空間，將原本的傳統商住用途轉化為多元化現代商業空間。項目同時獲得香港綠色建築議會的綠建環評（BEAM Plus）認證，在能源效率、用水管理及室內環境質素等方面均達到一定標準，體現了現代市區重建項目兼顧可持續發展之趨勢。

建築師並未因新建築而完全脫離周圍環境，反而以現代物料與手法回應街道的歷史與地形，此種設計手法可稱為「歷史文脈延續」——新建築並非取代舊有記憶，而是與之對話。

### 歷史事件與背景

#### 開埠初期與街道形成

- 1851年：砵典乍街建成，因應中環一帶陡峭的地勢而鋪設石階，方便居民往來皇后大道中與荷李活道。
- 1858年：街道正式命名為「砵典乍街」，以紀念香港第一任總督砵甸乍爵士。由於全段街道均以石塊鋪砌，民間普遍俗稱其為「石板街」。

#### 20世紀商住發展與街道特色

- 20世紀初至中葉：砵典乍街兩旁陸續興建多層高的唐樓，成為華人聚居與經商的混合區。街道上逐漸形成市集，售賣雜貨、日用品及節慶用品。
- 1970-2000年代：該區發展為售賣節慶裝飾、戲服及雜貨的特色街道，成為中環極具本土文化特色的旅遊地標。砵典乍街45號原址在這段期間主要作為傳統商住或零售用途。

#### 21世紀市區重建與現代活化

- 2010年代中期：私人發展商基匯資本收購砵典乍街45號及周邊地段，啟動重建活化計劃。項目旨在保留地區歷史文脈的同時，注入現代商業與創意元素。
- 2018年：The Steps · H Code 落成啟用。建築由著名建築師事務所巴馬丹拿集團設計，其階梯式露台設計直接致敬「石板街」的地理特徵。大廈引入了餐飲、零售及創意辦公空間，並獲得香港綠色建築議會的綠建環評（BEAM Plus）認證，成為中環新舊交融的現代地標。

## 五、導賞員現場講稿

### 開場白

各位團友，大家好。歡迎嚟到中環砵典乍街。我哋而家企喺呢條街上面，望住眼前呢座現代感十足嘅建築——佢就係 The Steps · H Code，地址係砵典乍街45號。

請大家先抬頭望一望呢座大廈嘅外觀。你會見到佢同旁邊嘅舊樓好唔同——大量玻璃幕牆、金屬元素，仲有一級一級嘅露台設計。呢個「階梯式」嘅外觀，就係我哋今日要講嘅第一個重點。今日我哋會由腳下嘅石板街講起，一路講到眼前呢座現代建築點樣同超過160年嘅街道歷史產生對話。

### 各站點

### 站點一：石板街的由來

#### 現場觀察重點

請大家低頭望一望地面——你會見到一塊一塊嘅石板。呢條就係香港人好熟悉嘅「石板街」。請大家留意地面嘅石塊鋪砌方式：呢啲石板唔係隨便鋪嘅，而係因應中環一帶陡峭嘅地勢，一級一級咁鋪出嚟，方便居民往來皇后大道中同荷李活道。大家可以親手摸下呢啲石板，感受一下超過160年嘅歷史質感。

#### 歷史故事

咁點解叫「砵典乍街」呢？原來喺1851年，即係香港開埠初期，政府起咗呢條街。到咗1858年，正式命名為「砵典乍街」，紀念香港第一任總督——砵甸乍爵士。不過，因為全段街道都係用石塊鋪砌，民間就習慣叫佢做「石板街」。呢個俗稱一直流傳到而家，可以話係香港最早期嘅街道記憶之一。砵甸乍爵士全名係亨利·砵甸乍，佢喺1843年成為香港第一任總督，任期雖然唔長，但呢條街就永遠記住咗佢個名。

### 站點二：從唐樓到特色市集

#### 現場觀察重點

請大家望向街道兩旁，留意唔同年代嘅建築物並存嘅景象。有啲係舊式樓宇，有啲就係好似 The Steps · H Code 咁嘅新建築。大家可以觀察吓舊式唐樓嘅騎樓設計同新建築嘅玻璃幕牆形成嘅對比——呢種新舊並存正正就係中環嘅特色。如果大家行過呢條街，一定見過掛到成個彩虹咁嘅嘉年華服裝、萬聖節裝飾、農曆新年用品，呢啲都係呢條街嘅標誌。

#### 歷史故事

喺20世紀初至中葉，砵典乍街兩旁陸續興建咗多層高嘅唐樓。嗰陣時呢度係華人聚居同經商嘅混合區，樓上住人，樓下開舖，好不熱鬧。街道上面逐漸形成市集，賣雜貨、日用品，仲有節慶用品。

去到1970至2000年代，呢區發展成為一個好有特色嘅街道——專門售賣節慶裝飾、戲服同雜貨。呢個就係中環極具本土文化特色嘅旅遊地標。而 The Steps · H Code 呢個位置，喺嗰段時間主要都係傳統嘅商住或者零售用途。可以話，呢度見證住中環由開埠到而家嘅商業變遷。

### 站點三：現代活化——The Steps · H Code 的誕生

#### 現場觀察重點

請大家再細心睇 The Steps · H Code 嘅外牆設計。留意佢嘅階梯式露台——每一層嘅露台都好似向後退咁，形成一級一級嘅效果。大家可以由下往上望，數吓有幾多層露台，感受一下呢個設計同腳下石板街嘅呼應關係。

#### 歷史故事

喺2010年代中期，私人發展商基匯資本收購咗砵典乍街45號同周邊地段，啟動重建活化計劃。項目嘅目標好明確：保留地區歷史文脈嘅同時，注入現代商業同創意元素。

到咗2018年，The Steps · H Code 正式落成啟用。呢座建築由著名建築師事務所巴馬丹拿集團設計——呢間公司其實就係以前嘅公和洋行，喺香港設計過好多標誌性建築，歷史可以追溯到19世紀。大廈引入咗餐飲、零售同創意辦公空間，將原本嘅傳統商住用途轉化為多元化嘅現代商業空間。

### 站點四：建築設計解讀

#### 現場觀察重點

請大家從三個方面仔細觀察呢座建築：

1. **階梯式露台**——大家由下往上望，會見到露台一層層咁向後退。呢個設計唔係隨意嘅，而係直接致敬「石板街」嘅地理特徵。你諗下，石板街本身就係一級一級嘅石階，建築師就將呢個意象放咗上大廈外牆，等座建築同條街有一種呼應嘅關係。
2. **玻璃幕牆同金屬元素**——建築採用現代簡約工業風，大量玻璃令到室內外有視覺連貫性，金屬元素就帶出一種都市感。
3. **空間規劃**——大廈入面引入咗餐飲、零售同創意辦公空間，將原本嘅傳統商住用途轉化為多元化嘅現代商業空間。

#### 歷史故事

建築師並冇因為係新建築就完全脫離周圍嘅環境。相反，佢哋用現代嘅物料同手法，去回應呢條街嘅歷史同地形。呢種設計手法，我哋叫做「歷史文脈延續」——新嘅建築唔係要取代舊嘅記憶，而係要同舊嘅記憶對話。

巴馬丹拿集團嘅歷史本身都好有故事。佢嘅前身係公和洋行，1868年已經喺香港成立，設計過唔少地標建築，包括舊匯豐銀行總行、中國銀行大廈等。所以由佢哋嚟設計 The Steps · H Code，本身就有一种歷史傳承嘅意味——一間有超過150年歷史嘅建築師事務所，為一條有超過160年歷史嘅街道，設計一座現代建築。

### 站點五：綠色建築認證

#### 現場觀察重點

雖然環保設計未必一眼就睇得到，但大家可以留意大廈嘅玻璃幕牆——呢啲通常都有節能嘅考慮，例如減少太陽熱力進入室內，從而降低冷氣消耗。大家亦可以留意大廈嘅整體通風設計，階梯式露台除咗呼應石板街之外，亦可以改善建築嘅自然通風效果。

#### 歷史故事

The Steps · H Code 獲得咗香港綠色建築議會嘅綠建環評（BEAM Plus）認證。呢個認證係香港本地嘅綠色建築評級系統，會評估建築喺能源效率、用水管理、室內環境質素等各方面嘅表現。能夠攞到呢個認證，代表 The Steps · H Code 喺環保設計上面達到咗一定嘅標準。

呢點亦都反映咗一個趨勢：就算係喺中環呢個寸金尺土嘅地方，新建築都要兼顧可持續發展嘅要求。市區重建唔淨止係拆舊樓起新樓，而係要喺歷史保育、商業發展同環境保護之間搵到平衡。

### 結語

各位團友，我哋今日企喺砵典乍街45號前面，其實係企喺一個好特別嘅時空交匯點。

請大家做一個對比——望一望腳下嘅石板街，再望一望眼前嘅 The Steps · H Code。一邊係1850年代鋪設嘅石階，另一邊係2018年落成嘅現代建築。中間相隔咗超過160年，但兩者之間又有一種微妙嘅連繫——就係「階梯」呢個意象。

砵典乍街由1851年建成開始，經歷過唐樓林立嘅華人商住區時期，發展到節慶用品嘅特色街道，再到今日 The Steps · H Code 嘅現代活化。每一個階段都為呢條街加添咗新嘅一層記憶。

而 The Steps · H Code 最特別嘅地方，就係佢用現代嘅建築語言，去回應呢條街超過一個半世紀嘅歷史。階梯式嘅露台設計，就好似同腳下嘅石板街講：「我記得你，我致敬你。」

呢個就係中環嘅魅力——新與舊唔係對立，而係共存；歷史唔係包袱，而係創新嘅靈感來源。

多謝大家，我哋嘅導賞到此為止。如果大家有興趣，可以行入 The Steps · H Code 入面睇下，感受一下現代空間同歷史文脈嘅結合。仲有咩問題，歡迎而家問。
