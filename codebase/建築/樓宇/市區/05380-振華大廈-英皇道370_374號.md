## 二、歷史脈絡與建築特色

### 建築風格與特色

振華大廈屬於香港1960年代典型的**現代主義實用建築**，其建築特徵反映戰後香港的社會經濟狀況與迫切的住房需求。建築採用鋼筋混凝土框架結構，立面設計簡潔，以直線條為主，無多餘裝飾性構件，充分體現「形式追隨功能」的現代主義核心理念。

| 特徵 | 描述 |
|------|------|
| 結構 | 鋼筋混凝土框架結構 |
| 立面 | 簡潔直線設計，無裝飾性構件 |
| 功能佈局 | 地面層商舖，上層住宅（下舖上居） |
| 窗戶 | 矩形鋼窗或鋁窗，排列規律 |
| 材質 | 以混凝土為主，外牆以批盪處理 |
| 命名文化 | 「振華」反映戰後振興中華的社會思潮 |

振華大廈的建築風格與同時期北角英皇道沿線的多棟住宅大廈一致，共同構成北角戰後城市景觀的重要組成部分。這類建築的設計回應了當時香港面臨的迫切住房需求，以實用性和經濟性為主要考量，體現了1960年代香港建築的時代特徵。建築命名「振華」二字，更反映了戰後華人社會普遍存在的「振興中華」時代思潮，為冰冷的建築實體注入了人文歷史意涵。

### 歷史事件與背景

#### 戰後北角發展期

- 1950年代：北角地區在二戰後迅速發展，大量上海移民及華南移民湧入，北角一度有「小上海」之稱。英皇道沿線因交通方便，成為住宅與商業混合發展的主要街道。振華大廈所處地段鄰近北角核心區域，具備良好發展潛力。

- 1960年代：根據北角英皇道沿線的建築發展脈絡，振華大廈推測於此時期興建，屬於戰後香港人口急增背景下興建的典型多層住宅大廈。建築採用鋼筋混凝土結構，地面層為商舖，上層為住宅單位，反映當時「下舖上居」的常見建築模式。

#### 建築風格與特色

- 1960-1970年代：振華大廈展現典型的香港1960年代現代主義實用建築風格，特徵包括簡潔的立面設計（無多餘裝飾）、鋼筋混凝土結構（注重功能性）、地面層設商舖上層為住宅單位（下舖上居模式）、採用實用主義設計理念回應當時大量人口住房需求，建築命名「振華」反映戰後華人社會振興中華的時代精神。

#### 北角社區變遷

- 1970-1980年代：北角逐漸發展成為港島東區的重要商住樞紐，英皇道沿線商業活動日益頻繁。振華大廈所在的英皇道370-374號一帶，鄰近北角電車總站及多條巴士線路，交通便捷，成為區內活躍的商住地段。

- 1990年代至今：北角經歷城市更新與社區轉型，新式住宅大廈陸續落成，但振華大廈等1960年代建築仍保留原貌，見證北角半個世紀的社區變遷。大廈目前仍作商住用途，是北角英皇道沿線戰後建築群的一部分。

#### 樓宇安全與維修

- 2010年代：隨著《建築物條例》對舊式樓宇的安全要求提高，振華大廈作為樓齡超過50年的建築，須按屋宇署的「強制驗樓計劃」進行定期檢查及維修。此計劃適用於樓齡達30年或以上的私人樓宇，業主須每10年進行一次訂明檢驗。

## 五、導賞員現場講稿

### 開場白

各位團友，大家好！歡迎來到港島東區充滿活力的北角。今日我哋會企喺車水馬龍嘅英皇道上，目光要聚焦嘅，係我身旁呢一座看似平凡、卻滿載著半個世紀香港故事嘅建築——振華大廈。

北角，係一個充滿故事嘅地方。由戰後嘅「小上海」，到今日港島東區嘅商住樞紐，呢度嘅每一棟建築，都係香港歷史嘅見證。而振華大廈，就係其中一座最具代表性嘅戰後實用建築。接落嚟我會帶大家從幾個唔同嘅角度，去解讀呢座建築背後嘅歷史密碼。

### 振華大廈外觀與建築風格

#### 現場觀察重點

大家不妨企定定，抬頭望一望呢座大廈嘅外牆。振華大廈位於英皇道370至374號，係一座典型嘅「下舖上居」商住大廈。從建築風格嚟睇，佢展現咗1960年代香港非常流行嘅「現代主義實用建築」風格。大家有冇留意到以下幾個重點：

1. **立面設計**：非常簡潔，冇乜多餘嘅裝飾，以直線條為主。
2. **結構材質**：鋼筋混凝土結構，係當時最先進嘅建築技術。
3. **窗戶排列**：矩形窗戶排列規律，注重採光同通風嘅實用功能。
4. **功能佈局**：地面層做商舖，上層做住宅，係典型嘅「下舖上居」設計。

呢種以鋼筋混凝土起嘅建築，最注重嘅就係功能性。雖然佢冇華麗嘅古典雕花，但呢種簡約嘅直線條，本身就係一種時代嘅美學。

#### 歷史故事

講到呢座大廈嘅誕生，我哋要將時間推返去1950至1960年代。二戰結束之後，北角迎來咗翻天覆地嘅變化。當時大量上海移民同華南地區嘅移民湧入香港，北角更一度有「小上海」之稱。英皇道沿線因為交通方便，好快就發展成為住宅同商業混合嘅主要街道。

根據北角英皇道沿線嘅建築發展脈絡，振華大廈推測就係喺1960年代呢個人口急增嘅背景下興建嘅。當時香港面對迫切嘅住屋問題，好似振華大廈呢類多層住宅大廈便應運而生。地面層做生意，樓上住人，呢種「下舖上居」嘅模式，養活咗唔少基層家庭，亦見證咗香港人當年拼搏求存嘅精神。

#### 現場觀察重點
