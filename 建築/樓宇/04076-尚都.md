## 二、歷史脈絡與建築特色

### 建築風格與特色

尚都所處的順寧道沿線，建築風格主要反映香港戰後（1950–1970年代）典型的多層住宅建築特徵：

| 特徵 | 描述 |
|------|------|
| **建築形態** | 多層條形住宅，沿街排列，形成連續街道界面 |
| **結構形式** | 鋼筋混凝土框架結構，取代戰前磚木結構 |
| **立面處理** | 簡約實用主義風格，外牆以批盪或洗水石米為主，裝飾極少 |
| **騎樓設計** | 部分樓宇設有懸挑式騎樓（俗稱「吊腳騎樓」），為地面層提供遮陽避雨空間 |
| **窗戶設計** | 採用鋼窗或鋁窗，排列規整，反映功能性考量 |
| **地面層用途** | 多作商舖用途，形成「下舖上居」的混合用途模式 |

**風格定位**：此類建築不屬於西方古典復興或裝飾藝術風格，而是反映香港戰後「實用至上」的建築思潮——在資源有限、人口急增的背景下，以最經濟的方式提供最大量的居住空間。這種建築風格在香港舊區（如深水埗、旺角、土瓜灣等）廣泛存在，構成香港城市景觀的重要基層。

### 歷史事件與背景

#### 深水埗早期城市化時期（1920s–1940s）

- 1920年代：深水埗作為九龍半島西部傳統墟市，沿青山道一帶逐步城市化。英國殖民政府於1920年代開始在深水埗進行有系統的街道規劃，順寧道所在區域被納入九龍市區發展範圍。
- 1930年代：深水埗區人口增長迅速，區內出現大量唐樓建築。順寧道一帶在此時期逐步形成住宅街道格局，沿街以3至4層高的戰前唐樓為主。
- 1941–1945年：日佔時期，深水埗區遭受嚴重破壞，區內不少建築物損毀或失修。日軍曾徵用深水埗軍營（位於今荔枝角道與東京街一帶）作戰俘營，對周邊地區造成影響。

#### 戰後重建與住宅發展時期（1950s–1970s）

- 1950年代：戰後大量內地移民湧入香港，深水埗成為人口最密集的地區之一。順寧道沿線出現大量以混凝土興建的5至6層住宅樓宇，取代原有戰前唐樓。此類建築多採用簡約實用主義風格，外牆以洗水石米或批盪為主。
- 1960年代：深水埗區持續高密度發展，順寧道一帶住宅樓宇密集排列。此時期建築普遍採用懸挑式騎樓（俗稱「吊腳騎樓」），以增加可用樓面面積，同時為地面層行人提供遮蔽。
- 1970年代：香港政府於1970年代推行《建築物（規劃）規例》修訂，對樓宇高度、間距及設施標準提出新要求。順寧道部分較舊樓宇在此時期進行維修或局部改建。

#### 城市更新與保育關注時期（1980s–2000s）

- 1980年代：深水埗區老化問題日漸顯著，部分戰後樓宇結構老化。市區重建局前身——土地發展公司於1988年成立，開始關注深水埗等舊區的重建潛力。
- 1990年代：深水埗區出現零星重建項目，部分舊樓被收購拆卸後重建為較高層住宅。順寧道沿線保留大量1960年代建成的多層住宅，形成今日所見的街道面貌。
- 2000年代：市區重建局於2001年正式成立，深水埗被列為重點重建區之一。順寧道一帶部分樓宇被納入重建研究範圍，但亦有部分因業權分散或具社區特色而保留至今。

#### 當代社區與導賞關注時期（2010s–至今）

- 2010年代：深水埗區的建築保育意識提升，民間團體及區議會開始組織社區導賞活動，關注戰後住宅建築的歷史價值與社區記憶。順寧道沿線樓宇作為深水埗戰後住宅發展的典型代表，被納入部分社區導賞路線。
- 2020年代：「尚都」作為順寧道83號的現有建築，被列入香港樓宇導賞團的關注點之一，反映深水埗區戰後住宅建築在城市記憶與社區身份中的角色。

## 五、導賞員現場講稿

### 開場白

各位團友，大家好！歡迎參加今日的深水埗建築導賞團。我哋而家企嘅位置，就係深水埗順寧道83號——「尚都」嘅門外。

大家初初望落去，可能會覺得呢棟樓平平無奇：冇金碧輝煌嘅裝飾，又唔係咩法定古蹟。但係，如果要真正讀懂深水埗，甚至係香港戰後基層社會嘅發展史，我哋就一定要由呢啲看似普通嘅街角建築講起。今日，我就帶大家由下而上，由外到內，解構呢棟建築背後嘅故事。

### 尚都（順寧道83號）

#### 現場觀察重點

首先，請大家稍微退後兩步，抬頭望一望「尚都」嘅外牆同埋整體結構。大家可以留意到幾個好重要嘅建築特徵：

**第一，建築形態同結構。** 呢棟係典型嘅多層條形住宅，沿街排列，形成咗一個連續嘅街道界面。佢採用咗鋼筋混凝土框架結構。大家要知道，喺戰前，深水埗一帶嘅唐樓多數係磚木結構嘅，但戰後起樓，為咗安全同效率，全面轉用鋼筋混凝土。

**第二，立面處理。** 大家見到佢外牆主要係批盪或者洗水石米，裝飾極少。呢種風格，我哋叫佢做「簡約實用主義」。喺1950至1970年代，香港資源有限，但人口就急增，當時嘅建築思潮就係「實用至上」——用最經濟嘅方式，提供最大量嘅居住空間。所以佢冇西方古典復興嘅雕花，亦冇裝飾藝術（Art Deco）嘅華麗線條，但求實用。

**第三，騎樓設計。** 請大家望向二樓以上向外懸挑嘅部分。呢個就係香港戰後建築好經典嘅「懸挑式騎樓」，俗稱「吊腳騎樓」。點解要咁設計？因為當時地少人多，發展商為咗增加可用樓面面積，就將樓層向外懸挑。同時，呢啲騎樓為地面層嘅行人提供咗一個遮陽避雨嘅空間。大家而家企喺下面，係咪覺得冇咁曬、冇咁淋？呢個就係前人嘅建築智慧，兼顧咗私人利益同公共空間嘅需要。

**第四，「下舖上居」嘅混合模式。** 大家望一望地面層，而家主要係商舖，樓上就係住宅。呢種「下舖上居」嘅模式，正正就係深水埗呢個傳統墟市同基層社區嘅靈魂所在，生活同生計緊密扣連。

#### 歷史故事

睇完建築外觀，我哋將時間推返轉頭，講下順寧道一帶嘅歷史變遷。

喺1920年代，深水埗仲係九龍半島西部嘅一個傳統墟市。當時英國殖民政府開始喺度進行有系統嘅街道規劃，順寧道就係喺嗰陣時被納入九龍市區發展範圍。去到1930年代，順寧道一帶已經形成咗住宅街道格局，當時沿街主要係3至4層高嘅戰前唐樓。

不過，好景不常。1941到1945年日佔時期，深水埗區遭受咗嚴重破壞。講到呢度，同大家分享一個沉重啲嘅歷史：距離我哋唔遠嘅荔枝角道同東京街一帶，當年係深水埗軍營。日軍佔領香港期間，徵用咗呢個軍營做戰俘營，關押咗大量盟軍戰俘。戰爭令到區內好多建築物損毀或者失修。

戰後，1950年代，大量內地移民湧入香港，深水埗因為地理位置同租金平，成為咗人口最密集嘅地區之一。為咗安置暴增嘅人口，政府同民間開始大量起樓。順寧道沿線嘅戰前唐樓逐漸被拆卸，取而代之嘅，就係好似「尚都」呢類以混凝土興建、5至6層高嘅住宅樓宇。我哋而家見到嘅「尚都」，雖然確切嘅落成年份需要翻查屋宇署檔案先可以百分百確認，但佢好大機會就喺呢個戰後重建嘅浪潮中誕生，見證住深水埗由戰後廢墟中重新出發。

去到1980至1990年代，深水埗區老化問題日漸顯著。1988年，市區重建局嘅前身——土地發展公司成立，開始關注深水埗等舊區嘅重建潛力。2001年市建局正式成立後，深水埗被列為重點重建區之一。順寧道沿線有部分舊樓被收購重建，變成咗更高層嘅住宅；但同時，亦有部分樓宇因為業權分散，或者因為佢哋承載住社區特色而保留至今。「尚都」就係其中之一，佢企喺度，為我哋保留咗1960年代深水埗街道嘅原貌。

### 結語

時至今日，雖然「尚都」並冇被列入古物古蹟辦事處嘅法定古蹟或已評級歷史建築名冊，但佢嘅價值並唔在於有幾宏偉或者有幾奢華。佢嘅價值在於，佢係深水埗戰後住宅發展嘅典型代表，記錄咗香港人喺資源匱乏年代嘅務實同堅韌。佢嘅騎樓、佢嘅批盪外牆、佢嘅下舖上居，全部都係構成香港城市景觀嘅重要基層，亦係深水埗社區身份認同嘅一部分。

下次當大家再行過深水埗嘅街道，不妨多抬頭望望呢啲樸實無華嘅戰後建築，佢哋每一塊磚、每一條騎樓柱，都在默默訴說緊香港基層社會嘅奮鬥故事。

好，我哋喺度嘅講解就到呢度。大家有冇咩問題想問？如果冇，我哋就跟住行去下一個導賞點。
