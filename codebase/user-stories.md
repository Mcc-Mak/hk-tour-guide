# 使用者故事

## US-01：導賞員查閱手冊

**作為**一名香港建築導賞員，
**我希望**能在網站上查閱特定建築的導賞手冊，
**以便**在帶團前準備導賞內容及歷史背景資料。

**驗收條件：**
- 手冊以繁體中文撰寫，遵循六段式標準結構
- 可透過 mdBook 搜尋功能查找建築名稱
- 每份手冊包含導賞路線建議及現場講稿

---

## US-02：研究人員驗證歷史資料

**作為**一名香港歷史研究人員，
**我希望**每份手冊附有 CL 1-5 可信度評級及官方檔案連結，
**以便**追溯資料來源並評估內容可靠性。

**驗收條件：**
- 每份手冊包含「事實查核與可信度評級表（CL 1-5）」
- 歷史檔案連結以 Markdown 超連結格式呈現，指向官方機構網域
- 連結由 CrewAI 研究員動態產出，非預先寫死

---

## US-03：專案負責人監控管線進度

**作為**專案負責人，
**我希望**能查看建築矩陣的 Emoji 狀態（🌚🌒🌗🌕），
**以便**掌握整體生成進度。

**驗收條件：**
- 矩陣子檔案即時反映每棟建築的工作進度
- 已完成項目顯示 🌕 及歷史檔案連結
- 管線執行日誌可即時追蹤

---

## US-04：開發者執行管線

**作為**開發者，
**我希望**能以指令行啟動管線並選擇執行範圍，
**以便**批次或優先處理特定建築。

**驗收條件：**
- 啟動選單 TUI 提供四種模式：全部 / 僅未開始 / 優先先行 / 離開
- `--priority-only` 旗標可跳過 TUI 直接處理優先建築
- `--priority-first` 旗標可優先處理後續接全部未完成項目
- LLM 失敗時自動備援，不中斷管線

---

## US-05：公眾瀏覽導賞資訊

**作為**一名對香港建築有興趣的公眾人士，
**我希望**能在 GitHub Pages 上瀏覽導賞手冊，
**以便**了解香港建築的歷史與特色。

**驗收條件：**
- mdBook 網站公開可訪問
- 支援繁體中文介面及搜尋
- 網址：`https://mcc-mak.github.io/hk-tour-guide/`
