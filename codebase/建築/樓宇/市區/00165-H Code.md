## 二、歷史脈絡與建築特色

### 建築風格與特色

H Code 的原建築屬於**戰前廣州式騎樓唐樓**風格，具有以下建築特徵：

1. **騎樓設計**：建築地面層後退形成有蓋行人道，為嶺南地區常見的建築形式，適應香港亞熱帶氣候，既可遮陽又可擋雨。
2. **下舖上居格局**：反映20世紀初華人商住混合的傳統生活模式，地下為店舖經營空間，樓上為住宅。
3. **磚木結構**：採用傳統磚牆承重配合木樓板結構，進深狹長，通風與採光主要依靠前方騎樓及後方天井。
4. **裝飾元素**：外牆保留部分古典裝飾線條，體現當時中西合璧的建築美學，反映香港華人社會融合中西文化的生活模式。
5. **石板街環境**：建築座落於著名的砵典乍街石板路上，與街道歷史環境形成完整的文化景觀。

活化後的 H Code 在保留歷史外觀的同時，內部注入現代建築元素，體現**「修舊如舊、內部更新」**的保育理念。外牆立面與騎樓特色被完整保留，甚至磚牆的質感都盡量還原；內部則改造成現代化空間，引入藝術畫廊、文創零售、特色餐飲等業態，成為中環文化地標之一。

### 歷史事件與背景

#### 街道奠基時期

- 1858年：砵典乍街建成，以香港第一任總督砵甸乍爵士（Sir Henry Pottinger）命名。街道因鋪設石板路面，俗稱「石板街」，成為中環最早開發的街道之一。

#### 戰前唐樓發展時期

- 1930年代：H Code 所在的砵典乍街45號建築相信建於此時期，為典型戰前廣州式騎樓唐樓。該類建築特色為下舖上居、狹長進深、設有騎樓以遮陽擋雨，反映當時華人商住混合的生活模式。
- 1930年代至1941年：建築作為商住用途，地下為店舖，樓上為住宅，見證中環華人商業區的繁榮發展。

#### 日佔時期

- 1941年12月至1945年8月：香港被日軍佔領，中環地區商業活動大幅萎縮，砵典乍街一帶建築受到不同程度的影響，部分建築遭破壞或改作他用。

#### 戰後修復與商業發展時期

- 1945年後：戰後香港經濟逐步復甦，砵典乍街45號建築恢復商住用途。中環作為金融商業中心急速發展，該區唐樓逐漸被更高密度的商業大廈取代，但部分戰前唐樓因業權或其他原因得以保留。
- 1960年代至2000年代：建築持續作商住用途，隨著中環商業化程度加深，該類戰前唐樓的保育價值逐漸受到社會關注。

#### 保育活化時期

- 2010年代中期：基匯資本（Gaw Capital Partners）收購砵典乍街45號物業，啟動活化保育工程。項目命名為「H Code」，「H」代表香港及砵典乍街的歷史連繫。
- 2018年：H Code 正式開幕。活化工程保留了建築原有的外牆立面和騎樓特色，內部則改造成現代化空間，引入藝術畫廊、文創零售、特色餐飲等業態，成為中環文化地標之一。
- 2019年至今：H Code 成為中環文化導賞路線的熱門景點，定期舉辦藝術展覽及文化活動，延續砵典乍街的歷史文化脈絡。

## 五、導賞員現場講稿

### 開場白

各位團友，大家好！歡迎嚟到中環。今日我哋企喺度嘅地方，係香港最早期開發嘅街道之一——砵典乍街。不過，相信好多人都習慣叫佢做「石板街」。而喺我哋面前呢棟充滿古典同現代交錯美感嘅建築，就係今日導賞嘅主角：H Code。

今日我哋會用大約45至60分鐘，由腳下嘅石板路開始，一路睇到建築嘅外觀，最後入去 H Code 嘅內部空間，親身感受呢棟建築由1858年到而家，超過一個半世紀嘅歷史變遷。

### 砵典乍街（石板街）

#### 現場觀察重點

[導賞員動作：引導團友低頭觀察地面]

大家不妨先低頭望吓腳下呢一塊塊凹凸不平嘅石板。砵典乍街早喺1858年就已經建成，以香港第一任總督砵甸乍爵士命名。因為中環地勢陡峭，當年政府特別用大塊花崗岩鋪設路面，等啲雨水容易排走，行人亦唔會咁易跣倒。呢條石板街已經喺2010年被古物古蹟辦事處列為「一級歷史建築」，可以話係香港開埠初期嘅活化石。

大家留意吓石板嘅排列方式同埋磨損痕跡，呢啲都係百幾年嚟無數行人踩出嚟嘅歷史印記。

#### 歷史故事

砵典乍街嘅歷史，可以話係香港開埠初期城市發展嘅縮影。1858年，港英政府為咗連接中環海旁同半山區，開闢咗呢條街道，並以香港第一任總督砵甸乍爵士命名。當時中環地勢陡峭，政府特別用花崗岩石塊鋪設路面，一來方便排水，二來防止行人跣倒。呢種石板路面設計，成為咗砵典乍街最標誌性嘅特徵，「石板街」呢個俗稱亦由此而生。

去到2010年，古物古蹟辦事處將砵典乍街列為一級歷史建築，確認咗佢喺香港城市發展史上嘅重要地位。而家我哋行緊嘅每一塊石板，都承載住超過160年嘅歷史。

### H Code 建築外觀

#### 現場觀察重點

[導賞員動作：引導團友抬頭望向 H Code 的建築外觀]

睇完地下，我哋抬頭望一望面前呢棟 H Code。佢嘅前身，其實係一座相信建於1930年代嘅「戰前廣州式騎樓唐樓」。大家留意吓建築地面嗰層，佢係向後退咗入去，形成一個有蓋嘅行人道，呢個就係嶺南建築好出名嘅「騎樓」設計。喺香港呢種亞熱帶氣候，騎樓既可以遮太陽，又可以擋風雨，以前嘅街坊仲可以喺騎樓底乘涼傾偈。

再望吓外牆，大家會見到保留咗部分古典嘅裝飾線條，呢種中西合璧嘅美學，正正反映咗當年香港華人社會融合中西文化嘅生活模式。建築採用磚木結構，進深好長，通風同採光主要靠前面嘅騎樓同後面嘅天井。

#### 歷史故事

講起呢棟唐樓嘅歷史，佢見證住中環華人商業區嘅起跌。喺1930年代，呢度係典型嘅「下舖上居」格局。地下做緊生意，樓上就係一家人住嘅地方。當時嘅唐樓多數係磚木結構，進深好長，通風同採光主要靠前面嘅騎樓同後面嘅天井。

不過，好景不常。1941年12月，香港進入咗三年零八個月嘅日佔時期。當時中環嘅商業活動大幅萎縮，砵典乍街一帶嘅建築亦受到不同程度嘅影響，有啲被破壞，有啲被改作他用。呢棟唐樓都靜靜地咁捱過咗呢段動盪歲月。

戰後，香港經濟逐步復甦，中環急速發展成為金融商業中心。周圍嘅戰前唐樓一棟接一棟咁被拆卸，改建做更高密度嘅商業大廈。但係，砵典乍街45號呢棟唐樓，因為種種業權同歷史原因，奇蹟地保留咗落嚟，成為咗中環變遷嘅見證者。由1960年代至2000年代，建築持續作商住用途，隨著社會對保育嘅關注度提升，呢類戰前唐樓嘅價值逐漸被重新認識。

### H Code 內部空間

#### 現場觀察重點

[導賞員手勢指向 H Code 的入口，引導團友留意新舊交替的細節]

去到2010年代中期，基匯資本收購咗呢個物業，啟動活化保育工程，並且將佢命名為「H Code」。點解叫「H」？「H」代表咗香港，亦代表咗砵典乍街嘅歷史連繫。

2018年，H Code 正式開幕。大家如果行近啲睇，會發現活化工程採用咗「修舊如舊、內部更新」嘅保育理念。外牆立面同騎樓特色被完整保留，甚至連磚牆嘅質感都盡量還原；但係入到去裡面，就已經搖身一變，成為咗現代化嘅藝術、文化、零售同餐飲綜合空間。

等陣我哋入去之後，大家可以特別留意幾個細節：第一，保留咗嘅原始磚牆同新建築物料之間嘅過渡設計；第二，騎樓空間點樣被重新定義為展覽同休憩用途；第三，內部樓層嘅採光設計如何呼應原本唐樓嘅天井結構。

#### 歷史故事

呢種「修舊如舊、內部更新」嘅做法，令到一棟本來可能被時代淘汰嘅老建築，重新注入咗新生命。活化工程遵循《古物及古蹟條例》（香港法例第53章）及相關保育指引進行，保留咗建築原有嘅外牆立面同騎樓特色，同時將內部改造成適合現代用途嘅空間。

而家嘅 H Code，定期都會舉辦藝術展覽同文化活動，吸引咗好多對文化導賞有興趣嘅朋友嚟參觀。由2019年至今，H Code 已經成為中環文化導賞路線嘅熱門景點。佢唔單止係一個打卡熱點，更係一個延續緊砵典乍街歷史文化脈絡嘅活態地標。

呢棟建築嘅蛻變，代表咗香港對歷史保育嘅一種態度：唔係將老建築凝固成博物館嘅展品，而係畀佢繼續喺城市生活中扮演角色，用新嘅功能承載舊嘅記憶。

### 結語

各位團友，建築物嘅外殼雖然係死物，但入面嘅故事同埋人嘅活動，就賦予咗佢生命。由1858年嘅石板街，到1930年代嘅騎樓唐樓，再到2018年重生嘅 H Code，呢度濃縮咗香港超過一個半世紀嘅歷史。

等陣我哋就會入去 H Code 裡面參觀，大家可以親身感受吓「修舊如舊」嘅內部空間，同時亦可以喺裡面嘅文創店舖同畫廊，尋找吓新舊交融嘅香港文化痕跡。
