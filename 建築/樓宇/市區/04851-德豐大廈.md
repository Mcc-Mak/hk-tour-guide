## 二、歷史脈絡與建築特色

### 建築風格與特色

德豐大廈屬香港1960–1970年代典型的**戰後商住樓宇**（Tong Lau / Mixed-use Building）風格，具以下特徵：

| 特徵 | 描述 |
|------|------|
| **結構** | 鋼筋混凝土結構，取代戰前唐樓的磚木結構 |
| **立面** | 簡約實用主義，外牆以洗水石米或紙皮石鋪飾，缺乏裝飾性構件 |
| **功能佈局** | 地下商舖＋樓上住宅的垂直混合用途，反映香港高密度城市特徵 |
| **窗戶** | 採用鋁窗或鐵窗，排列規整，注重通風採光 |
| **招牌空間** | 外牆預留商舖招牌安裝位置，形成油麻地典型的街道視覺景觀 |
| **騎樓/走廊** | 部分沿街立面設有行人道上蓋或退縮空間，適應亞熱帶氣候 |

此類建築雖不具法定古蹟地位，但作為戰後九龍市區發展的物質見證，具有城市形態學與社會歷史研究價值。

### 歷史事件與背景

#### 油麻地填海與街道形成期

- 1860年代：九龍半島割讓予英國後，油麻地逐漸發展為漁民聚居及船隻停泊的港灣社區。
- 1870年代：港英政府於油麻地一帶展開填海工程，填海所得土地開闢新街道，新填地街（Reclamation Street）由此得名，成為油麻地核心商住街道之一。
- 1887年：油麻地差館街（今眾坊街）一帶的市區規劃逐步落實，新填地街沿線地塊開始劃分出售。

#### 戰前發展期

- 1900–1930年代：新填地街沿線發展為密集的商住混合街區，沿街建有戰前唐樓，地下為商舖、樓上為住宅，形成油麻地典型的街市與商業生活圈。
- 約1913年：油麻地果欄建成（位於新填地街與石龍街交界），其後逐步擴建，進一步帶動新填地街南段一帶的農產品貿易與人流。
- 1930年：油麻地戲院落成啟用（位於窩打老道與新填地街交界附近），成為區內重要娛樂場所，反映新填地街一帶已發展為成熟市區。

#### 日佔時期

- 1941–1945年：香港淪陷期間，油麻地區商業活動大幅萎縮，新填地街沿線不少戰前建築失修。部分樓宇被日軍徵用。

#### 戰後重建與現代化發展期

- 1950–1960年代：戰後人口急增，油麻地新填地街一帶大量戰前唐樓被重建為數層高的鋼筋混凝土商住樓宇。德豐大廈所處之地段，極可能於此時期由舊式唐樓重建為現代商住大廈。
- 1960–1970年代：油麻地持續高密度城市化，新填地街沿線樓宇密集興建，形成今日所見的街景面貌。德豐大廈作為區內典型商住樓宇，地下為商舖（常見為五金、飲食、零售），樓上為住宅單位。
- 1972年：政府推行「十年建屋計劃」，油麻地等舊區的私人樓宇更新速度加快。

#### 近現代時期——市區重建與保育關注

- 2000年代：市區重建局（URA）將油麻地列為重點重建區域之一，新填地街沿線部分舊樓被納入重建項目範圍。德豐大廈因樓齡漸高，亦受市區更新政策影響。
- 2010年代：油麻地保育議題升溫，民間關注舊區街景與社區網絡的保存。新填地街一帶的戰後商住樓宇群被視為反映1960–1970年代九龍市區建築形態的典型範例。
