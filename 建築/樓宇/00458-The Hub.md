## 二、歷史脈絡與建築特色

### 建築風格與特色

The Hub 的建築風格反映了香港九龍灣工業區從傳統工業用途向現代商貿用途轉型的典型特徵：

1. **外立面設計**：採用現代主義簡約風格，以玻璃幕牆配合金屬飾面板，取代原有工廈的實牆與小窗設計，提升採光與商業形象。
2. **結構特徵**：保留原工業大廈的鋼筋混凝土框架結構，樓底高度較一般寫字樓為高（約3.5至4米），反映其工業建築的結構遺產。
3. **功能轉型**：內部空間由原來的開放式工廠樓面，間隔為現代化寫字樓單位及共享工作空間，體現「工廈活化」的建築策略。
4. **入口與大堂**：經翻新後設有現代化商業大堂，與原工廈的貨運入口設計形成對比，標誌著建築功能的根本轉變。

### 歷史事件與背景

#### 九龍灣填海與工業區開發期

- 1970年代：香港政府於九龍灣進行大規模填海工程，開闢九龍灣工業區，業勤街為該區主要街道之一，旨在配合香港製造業黃金期的工業用地需求。
- 1970年代後期至1980年代初期：業勤街沿線陸續興建多層工業大廈，The Hub 前身（或原址建築）極可能於此時期落成，作為標準分層工業大廈用途，容納輕工業、電子組裝、塑膠及紡織相關工場。

#### 工業北移與轉型期

- 1990年代：隨著中國大陸改革開放及香港製造業大規模北移，九龍灣工業區出現大量空置工廠單位。業勤街一帶工廈逐步轉型，部分樓層改作倉儲、物流及小型辦公室用途。
- 2000年代初期：九龍灣工業區持續轉型，政府推動「工業用地改劃」政策，部分工廈申請改作商業或數據中心用途。業勤街23號原工業大廈可能於此時期開始規劃改建或活化。

#### 重建與現代化期

- 2010年代：九龍灣商貿區逐漸成形，業勤街一帶多棟舊工廈重建或活化為現代化商業大廈。The Hub 作為改建或重建後的商業大廈，名稱反映其定位為「樞紐」型商貿空間，提供寫字樓及靈活工作空間。
- 2010年代後期至2020年代：The Hub 作為九龍灣工業區轉型的代表性案例之一，展示香港工廈活化的建築趨勢。

## 五、導賞員現場講稿

### 開場白

各位朋友，歡迎參加今日嘅導賞團。我哋而家企喺九龍灣業勤街23號——The Hub 嘅門前。喺我哋開始講呢棟建築嘅故事之前，我想請大家先望一望四周圍嘅環境。

大家有冇留意到，呢一帶嘅街道名稱好似特別整齊？業勤街、宏開道、啟祥道——呢啲街道名稱其實反映咗1970年代政府開發九龍灣工業區嗰陣嘅規劃心思。「業勤」二字，顧名思義就係「勤於工業」咁解，帶住嗰種腳踏實地、勤力做工嘅精神。而家我哋企喺度，腳底下嘅土地，其實都係填海得嚟嘅。

### 各站點

### 九龍灣填海與工業區嘅誕生

#### 現場觀察重點

請大家留意業勤街嘅街道佈局——直線嘅街道、方正嘅地塊，呢種規整嘅格局係1970年代規劃工業區嘅典型手法。同舊區例如深水埗、油麻地嗰啲彎彎曲曲嘅街道好唔同，反映咗現代城市規劃嘅思路。

#### 歷史故事

等我先同大家講下九龍灣呢一區係點樣出現嘅。

我哋而家企嘅位置，屬於觀塘區。喺1970年代之前，九龍灣呢一帶仲係一片海面。當時香港政府決定喺度進行大規模填海工程，開闢出一個全新嘅工業區。點解要咁做呢？因為1960至70年代，正正係香港製造業嘅黃金時期——紡織、塑膠、電子、鐘錶，各行各業都蓬勃發展，工廠對土地嘅需求極之龐大。當時嘅觀塘工業區已經唔夠用，政府就需要開闢新嘅工業用地。

九龍灣工業區就係喺呢個背景下誕生。政府填海造地之後，規劃咗一條條整齊嘅街道，業勤街就係其中一條主要街道。沿住業勤街同埋周邊嘅街道，一座座多層工業大廈陸續拔地而起。

### 工廈嘅黃金歲月

#### 現場觀察重點

大家可以抬頭望一望 The Hub 嘅建築外觀。雖然經過咗現代化嘅翻新，但如果大家仔細觀察，仍然可以感受到佢作為工業大廈嘅一啲結構特徵——例如樓層之間嘅高度，比一般寫字樓要高。呢個係因為工廠需要擺放大型機器同埋貨物，樓底要夠高先至實用。呢種建築結構上嘅「工業基因」，就算係改變咗用途之後，都仲可以隱約見到。

#### 歷史故事

根據九龍灣工業區嘅發展時序，業勤街沿線嘅工業大廈主要喺1970年代後期至1980年代初期陸續落成。The Hub 嘅原址建築，好大機會都係喺呢段時期建成嘅。

大家可以想像一下當時嘅景象：呢棟建築當年係一座標準嘅分層工業大廈，入面容納咗大大小小嘅工場。嗰個年代，九龍灣工業區入面有各種各樣嘅輕工業——由電子零件組裝，到塑膠製品，再到紡織成衣，應有盡有。每一層樓可能分成幾個甚至十幾個單位，每個單位都係一間獨立嘅工場或者小型廠房。

每日朝早七八點鐘，成條業勤街就會好熱鬧——工人們陸陸續續返工，貨車喺街邊上上落落搬貨，升降機不停咁將人同貨物送到各層。呢度就係香港製造業最興旺嘅年代嘅真實寫照。

### 工業北移與空置危機

#### 現場觀察重點

大家可以望一望隔離或者對面嘅大廈。有啲舊式工廈到而家仲保留住原本嘅外觀——實牆設計、細窗戶、外牆上面可能仲見到舊式嘅招牌或者貨運標記。呢啲都係工業時代留低嘅痕跡。同 The Hub 經過翻新之後嘅現代化外觀形成強烈對比，正好展示咗九龍灣工業區轉型嘅不同階段。

#### 歷史故事

不過，好景不常。去到1990年代，香港嘅工業面貌出現咗翻天覆地嘅變化。

隨住中國大陸改革開放，珠三角地區提供咗大量廉價土地同勞動力，香港嘅製造業大規模北移。一間接一間嘅工廠將生產線搬晒過去大陸，香港嘅工廈就開始出現大量空置。

九龍灣工業區首當其衝。原本機器聲轟隆隆嘅工廠大廈，一層接一層咁空咗出嚟。有啲業主將單位改做倉庫，有啲就租俾小型公司做辦公室。嗰段時期，九龍灣嘅工廈入面，你可能會見到同一層樓有一間貨倉、一間設計公司、一間迷你倉，仲有一間教人彈結他嘅音樂教室——五花八門，乜都有。

呢種混雜嘅使用方式，雖然令工廈保持咗一定嘅使用率，但同時都帶嚟咗消防安全同埋管理上嘅問題。政府亦開始意識到，九龍灣工業區需要一個更清晰嘅轉型方向。

### 政策推動與規劃轉型

#### 現場觀察重點

請大家留意 The Hub 嘅外立面設計。同傳統工廈嗰種實牆加細窗嘅設計唔同，The Hub 採用咗現代主義嘅簡約風格，用玻璃幕牆同金屬飾面板去包裝建築外觀。呢種設計唔單止提升咗採光效果，更重要嘅係改變咗建築嘅「形象」——由工業大廈變成商業大廈，要俾人一種專業、現代嘅感覺。

#### 歷史故事

去到2000年代初期，政府開始認真處理工業區轉型嘅問題。城市規劃委員會逐步將九龍灣一帶嘅土地用途由「工業」改劃為「其他指定用途」註明「商貿」，容許工廈改建或者重建做商業大廈。

呢個政策轉變好重要。以前工廈要改做寫字樓，可能要面對好多限制同審批；改劃之後，業主就有更大嘅彈性去進行活化或者重建。規劃署亦都進行咗《九龍灣及觀塘商貿區規劃研究》，為成個區嘅轉型定下策略方向。

喺呢個大環境之下，業勤街23號嘅原工業大廈亦都踏上咗轉型之路。經過改建或者活化工程，佢變成咗今日我哋見到嘅 The Hub——一棟現代化嘅商業大廈。

### The Hub 嘅建築特色

#### 現場觀察重點

大家可以比較一下 The Hub 同旁邊未經活化嘅工廈。留意以下幾點：

1. **外牆物料**：The Hub 用玻璃幕牆，舊工廈用實牆
2. **窗戶大小**：The Hub 嘅窗面積大得多，舊工廈嘅窗細而密
3. **入口設計**：The Hub 有正式嘅商業大堂入口，舊工廈嘅入口偏向功能性
4. **整體形象**：The Hub 俾人現代、專業嘅感覺，舊工廈仲保留住工業時代嘅樸實感

#### 歷史故事

而家等我哋行近少少，仔細睇下 The Hub 嘅一啲建築細節。

首先，大家留意吓個入口同大堂。經過翻新之後，The Hub 設有現代化嘅商業大堂，同以前工廈嗰種以貨運為主嘅入口設計完全唔同。以前工廈嘅入口，主要考慮嘅係點樣方便貨車上落貨、點樣將大件貨物推入升降機。而家嘅商業大堂，考慮嘅係點樣營造專業嘅商務形象、點樣令訪客感到舒適。

不過，雖然外觀同入口經過大幅翻新，但建築嘅基本結構——鋼筋混凝土框架——仍然保留住。呢種「保留結構、更新外觀」嘅做法，係香港工廈活化嘅常見策略。一方面保留咗建築嘅結構遺產，另一方面賦予佢新嘅商業功能。

另外，我頭先提過，工廈嘅樓底比較高。The Hub 保留咗呢個特徵，樓底高度比一般寫字樓為高。對於現代商業用家嚟講，高樓底反而成為一個賣點——空間感更好，可以做更靈活嘅室內設計。

### 由「工廠」到「樞紐」

#### 現場觀察重點

請大家再退後幾步，遠觀 The Hub 喺整條業勤街上面嘅位置同形象。大家可以留意到，The Hub 喺一排舊式工廈中間顯得特別突出——玻璃幕牆反射住陽光，同兩旁嘅實牆建築形成好大對比。呢種視覺上嘅差異，正正就係九龍灣工業區轉型嘅最直接寫照。

#### 歷史故事

最後，我想同大家講下「The Hub」呢個名嘅意義。

「Hub」喺英文入面解作「樞紐」、「中心」。將一棟由工廈活化而成嘅商業大廈命名為「The Hub」，其實反映咗業主對呢棟建築嘅定位——佢唔再係一座工廠，而係一個商貿活動嘅樞紐。

呢個命名亦都呼應咗九龍灣嘅整體發展方向。經過幾十年嘅轉型，九龍灣已經由一個工業區，逐漸變成一個商貿區。MegaBox、國際展貿中心、各種寫字樓同商場陸續落成，九龍灣嘅面貌已經同1970年代完全唔同。

The Hub 嘅故事，其實就係香港工業區轉型嘅一個縮影——由填海造地、興建工廈、工業北移、空置危機，到政策推動、活化重建，最後變成現代化嘅商貿空間。每一棟經過活化嘅工廈，背後都有咁樣一個蛻變嘅故事。

### 結語

各位朋友，企喺 The Hub 門前，我哋睇到嘅唔單止係一棟商業大廈，而係香港經濟轉型嘅活歷史。

由1970年代嘅填海工程，到製造業黃金期嘅工廠大廈；由1990年代工業北移後嘅空置危機，到2000年代政策推動下嘅活化轉型——The Hub 見證咗香港由工業城市走向服務型經濟嘅整個歷程。

下次當大家行經九龍灣，見到呢啲經過活化嘅商業大廈嘅時候，不妨想像一下：幾十年前，呢度可能係一間紡織廠、一間電子零件工場，每日有幾百個工人喺度開工。而家，同一個地方，變成咗寫字樓同商貿空間。建築嘅用途變咗，但佢承載住嘅香港人拼搏精神，其實一直冇變。

多謝大家參與今日嘅導賞團。如果有任何問題，歡迎而家提出，我哋一齊討論。
