# 產品需求文件 (PRD)

## 1. 產品概述

### 1.1 產品名稱

香港建築導賞手冊（Hong Kong Building Tour Handbook）

### 1.2 目標使用者

| 使用者 | 使用場景 |
| :--- | :--- |
| 導賞員 | 帶團前查閱建築歷史、導賞路線及現場講稿 |
| 歷史研究人員 | 驗證手冊中的 CL 評級及官方檔案連結 |
| 公眾人士 | 瀏覽香港建築的歷史與特色 |
| 專案負責人 | 監控管線進度、管理矩陣狀態 |

### 1.3 價值主張

以 AI 自動化取代人工撰寫，為 20,210 棟建築批量生成結構化、事實查核過的繁體中文導賞手冊，並以可搜尋的 mdBook 網站形式公開發佈。

### 2.2 手冊結構（六段式）

每份手冊必須嚴格遵循以下章節：

1. **一、導賞概覽與地址資訊** — 建築基本資料表格 + 導賞路線建議
2. **二、歷史脈絡與建築特色** — 建築風格與特色 + 歷史事件與背景（以 `#### {歷史時期/特徵}` 分組，`- {年份}：{歷史描述}` 條列）
3. **三、事實查核與可信度評級表（CL 1-5）** — 歷史數據查核 + AI 幻覺過濾 + 整體可信度
4. **四、歷史檔案狀態宣告** — 可信性等級 + 歷史檔案連結（CrewAI 動態產出）
5. **五、導賞員現場講稿** — 開場白 + 各站點（現場觀察重點 + 歷史故事）+ 結語
6. **六、參考資料來源** — 官方檔案連結 + 參考文獻清單
